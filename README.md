# 九霄

> 像素修仙 Roguelike。三个修士，一座被灭门的山，九关往上走。

## 四层结构

```
三个角色        剑客 / 道人 / 魔头        ← 你是谁，为什么上山
      ↓
关外等级 1-30    修为、功法解锁          ← 长线成长，几十小时
      ↓
关内等级 0 起    道行、三选一            ← 一局的爆发，25 分钟
      ↓
九关情节        乱葬岗 → 九霄            ← 你为什么打
```

## 三个角色，三种代价

| | 剑客 · 陆青锋 | 道人 · 无尘 | 魔头 · 血衣 |
|---|---|---|---|
| 身份 | 山门守山人 | 云游散修 | 逃来的魔修 |
| 资源 | 气血 | 灵力 | 气血 + 魔气 |
| 代价 | 施法烧血 | 等灵力 | 入魔掉血 |
| 故事 | 问一句为什么 | 送人归山 | 止住自己的血 |

**三个角色的等级、修为、功法、剧情、关卡进度全部独立。**
只有"仙缘"共享——那是世界观的一致性。

## 两层等级

| | 关外 | 关内 |
|---|---|---|
| 范围 | 1-30，持久 | 每局从 0 |
| 资源 | 修为（通关获得） | 道行（击杀获得） |
| 作用 | 属性、功法解锁 | 三选一强化 |
| 每局 | — | 约 12 次升级 |

**关外给起点，关内给这一局的表现。**

关内永远约 12 次升级，不管关外多少级——否则高等级会滚雪球。

## 九关

| 关 | 地名 | 守关者 | 这一关讲什么 |
|---|---|---|---|
| 1 | 乱葬岗 | 尸傀 | 剑客打的是同门 |
| 2 | 断魂涧 | 涧中老蛟 | 第一次遇到比人强的 |
| 3 | 枯骨庙 ★ | 庙中骨佛 | 得残经中卷 |
| 4 | 万剑冢 | 剑冢守灵 | 得断剑 |
| 5 | 镜心湖 | 心魔 | 接受或拒绝 |
| 6 | 悬空栈道 ★ | 守栈人 | 师叔之死 |
| 7 | 双生洞 | 双子道人 | 分裂的主题 |
| 8 | 雷池 | 雷部残将 | 灭门真相 |
| 9 | 九霄 ★ | 道 | 放下 |

★ 大境界突破。地形共用，但每个角色走的顺序不同。
