# 九霄

> 像素修仙 Roguelike。一个散修从山门废墟出发，一路打到九霄之上。

## 三层结构

```
修炼三部（剑修 / 法修 / 魔修）   ← 你用什么代价变强
      ↓
法术进化（基础 → 进阶 → 融合）    ← 你怎么打
      ↓
九关情节（乱葬岗 → 九霄）         ← 你为什么打
```

**核心不是打怪，是进化。** 打怪只是燃料。

## 三条路，三种代价

| | 剑修 | 法修 | 魔修 |
|---|---|---|---|
| 资源 | 气血 | 灵力 | 气血 + 魔气 |
| 优势 | 稳，不依赖资源 | 爆发高，有控制 | 越打越强 |
| 代价 | 施法烧血 | 灵力耗尽就废 | 自身在流血 |

没有无代价的变强。选一条路，就是选一种代价。

## 法术进化

```
初始技能（选 2 个）
    ↓ 修满 5 级后二选一，不可逆
进阶分支
    ↓ 两个分支凑齐
融合（同部常见，跨部稀有）
```

比如：**青锋式 → 断岳式 + 罡风诀 → 万剑归宗**。
