# 九霄

> 像素修仙 Roguelike。掌心雷修满之后，能变成九霄天雷。

一个修士从山门出发，一层层往上打。每层是一个境界：炼气、筑基、金丹……一直到九霄之巅。

## 怎么玩

**核心不是打怪，是进化。**

1. 开局选两个法术（六个里挑两个）
2. 打怪掉碎片，吃够 5 个，法术修满
3. 修满时**二选一**挑进阶分支——**不可逆**
4. 两个法术的分支都凑齐，可以**融合**成新法术

比如：掌心雷选「五雷正法」，焚天印选「焚山煮海」，两者合体就是**九霄天雷**。

## 五个流派

| 流派 | 走法 | 强在哪 | 弱在哪 |
|---|---|---|---|
| 雷主 | 五雷正法 + 焚山煮海 → 九霄天雷 | 清场 | 冷却长，怕贴身 |
| 冰控 | 疾电诀 + 万里冰封 → 天霜雷狱 | 安全 | 打得慢 |
| 木火 | 不灭心火 + 回春藤 → 枯木逢春 | 不死 | 爆发乏力 |
| 金身 | 五雷正法 + 不动明王 → 不动雷音 | 反伤 | 前期弱 |
| 御风 | 疾电诀 + 风卷残云 → 风雷引 | 机动 | 要手速 |

详表见 `docs/skills.md`。
