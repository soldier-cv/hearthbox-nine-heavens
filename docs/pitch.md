# 九霄 · 一页纸

## 一句话

三个修士，一座被灭门的山。**一个要问，一个要送，一个要清账。**

## 核心动词

**进化。**

不是"打怪"，不是"躲弹幕"。每一局的核心决策是：
**这条路该往哪个方向走下去。**

打怪是燃料。故事是理由。

## 四层结构

```
三个角色        剑客 / 道人 / 魔头        ← 你是谁，为什么上山
      ↓
关外等级 1-30    修为、功法解锁          ← 长线成长
      ↓
关内等级 0 起    道行、三选一            ← 一局的爆发
      ↓
九关情节        乱葬岗 → 九霄            ← 你为什么打
```

**由外到内，一层比一层短。** 最外层约 30 小时，最内层 20 分钟。

## 三个角色 = 三个动词

| | 剑客 · 陆青锋 | 道人 · 无尘 | 魔头 · 血衣 |
|---|---|---|---|
| 身份 | 山门外门守山人 | 云游散修 | 被逐出门墙的魔修 |
| 动机 | 师门被灭，要问一句为什么 | 受垂死者所托 | 把血债结清 |
| 资源 | 气血 | 灵力 | 气血 + 魔气 |
| 代价 | 施法烧自己的血 | 等灵力（配额） | 入魔掉血，不打掉魔气 |
| **动词** | **守** | **行** | **杀** |
| 结局 | 知道真相 | 送人归山 | 血止住了 |

**三者的等级、修为、功法、剧情、关卡顺序全部独立。** 只有"仙缘"共享。

## 真正区分他们的不是技能，是"怎么算赢"

| | 剑客 | 道人 | 魔头 |
|---|---|---|---|
| 九关里"守"几次 | 3 | 2 | 0 |
| 九关里"到达"几次 | 2 | **7** | 0 |
| 九关里"杀"几次 | 4 | **0** | **9** |

**道人的九关里，没有任何一关要求他杀人。**
**魔头的九关里，每一关要求都是杀。**

这不是台词层面的差别，是**胜利条件**层面的差别。
玩家玩完道人的线，会真的没杀过人；玩完魔头的线，会只剩一个动词。

## 九个境界，三条路线

境界跟**位置**走，地名跟**角色**走。

|---|---|---|---|---|

| 3 | 金丹★ | 枯骨庙 `TRAP` | 乱葬岗 `SET` | 枯骨庙 `TRAP` |
| 4 | 元婴 | 万剑冢 `DUEL` | 镜心湖 `RUN` | 镜心湖 `DUEL` |
| 5 | 化神 | 镜心湖 `SET` | 万剑冢 `SWARM` | 悬空栈道 `SET` |
| 6 | 炼虚★ | 悬空栈道 `RUN` | 双生洞 `SET` | 双生洞 `DUO` |
| 7 | 合体 | 双生洞 `DUO` | 悬空栈道 `HUNT` | 断魂涧 `HUNT` |

**八种关卡形状**：`HOLD` 守 / `RUN` 走 / `HUNT` 追 / `SWARM` 围 /
`TRAP` 机关 / `DUEL` 对决 / `DUO` 双线 / `SET` 演出。

**三种目标**：守 / 达 / 杀。

```
8 形状 × 3 目标 ≈ 11 套代码，27 个关卡配置
```

## 两层等级

### 关外（持久）

```
1-30 级，靠修为提升
第 N 关通关给：1,200 + 600 × N（一局九关 37,800）
每级 3 点，自己分配：气血 / 伤害 / 冷却 / 暴击 / 移速 / 击杀回血
满级约 29 次九关（约 10 小时）
```

### 关内（临时）

```
每局从 0 开始，靠击杀得道行
满了三选一，一局固定 12 次
退出关卡就清空
```

**关外给起点，关内给这一局的表现。**

| | 关外 1 级 | 关外 22 级 |
|---|---|---|
| 进关卡气血 | 20,000 | 36,800 |
| 一击（不含关内） | 1,000 | 2,260 |
| 一击（含关内 10 次） | — | 8,400 |
| 关内还能升 | 12 次 | 12 次（一样） |

**关内永远 12 次升级**，不管关外多高。否则高等级会滚雪球。

## 数值：大数，两层括号

```
一击 = 800 × 关外括号 × 关内括号

关外括号 = 1 + 每级 6%
关内括号 = 1 + 每次三选一 26% + 资源满层 + 词条
```

| | 第 1 关 | 第 9 关 |
|---|---|---|
| 一击 | 1,000 | 8,400 |
| 杂兵血 | 4,000 | 33,600 |
| Boss 血 | 60,000 | 504,000 |

**"几下打死"全九关不变**：杂兵 4 下、精怪 10 下、妖将 30 下、Boss 60 下。
**数字在涨，手感不变。**

**为什么是千级**：两位数在 8px 像素字体上像调试信息；
而且五条加成线挤在两位数里，第二个乘区就爆了。

## 第一分钟

1. 选角色（只有剑客可选，另两个要解锁）
2. 进第一关：乱葬岗
3. 木牌立在坟中间。三具腐尸慢慢爬向木牌
4. 青锋式一剑砍倒——**伤害数字是 1,000**
5. 道行满了，弹出三选一：**强化青锋式 / 学会回风斩 / 气血 +1,200**

**第一分钟必须看到三件事**：

1. 这条路要付什么代价（**每砍一剑，自己的血在掉**）
2. 打怪能让你变强（**道行在涨，数字够大，看得见**）
3. 你要守的是个东西，不是杀够数量（**木牌在那儿，腐尸冲它去**）

## 和同类游戏的区别

| | 吸血鬼幸存者 | 哈迪斯 | 九霄 |
|---|---|---|---|
| 核心循环 | 自动打，玩家走位 | 房间推进 + 对话 | 闯关 + 角色养成 |
| 变强方式 | 武器升级 | 祝福组合 | 关外修为 + 关内三选一 |
| 角色 | 一个 | 一个（换武器） | **三个，各自独立，三套目标** |
| 叙事 | 弱 | 强（反复死亡推进） | 强（三段交叉的故事） |
| 代价 | 无 | 无 | **每个角色都在付出** |
| 关卡结构 | 全是"活到时间结束" | 全是"清房间" | **8 种形状，三种目标** |

**最关键的区别**：三个角色不是"三个职业"，是**三种代价 + 三种"怎么算赢"**。

## 不做什么

- **不做联机**
- **不做装备系统**（只有功法）
- **不做炼丹炼器**
- **不做支线**（一条主线九关，三个视角）
- **不做多结局**（三个角色各一个结局，没有"真结局"）
- **不做 3D**
- **不做角色自定义**（三个角色是写死的，不是捏人）
- **不做跨角色技能共享**（与"三人独立"冲突）

## 开发前必须清掉的坑

这几处是此前文档互相打架、照着写必然出错的地方。已经改，记在这里防止回退：

| 坑 | 症状 |
|---|---|
| 九关全是"撑满时间" | 玩到第 5 关开始分不清自己在哪一关 |
| 三个角色只是换顺序 | 同一块地形三个人走法一样，等于只有一个角色 |
| 同一地形三人同形状 | 枯骨庙三个人都是机关关、镜心湖三个人都是对决关 |
| 数值是两位数 | 随便加两层加成就爆，Boss 血也显得不厚 |
| 道人灵力 3/秒 | 他的输出只有剑客的 1/6，字面上打不过 |
| 双子洞 5 秒回 5% | 道人的 DPS 是负的，永远打不死 |
| 剑客技能消耗 0 | 违反"无代价不变强"的底线 |
| 剑客消耗写成 2% | 一关出手 120 次 = 240% 气血，**打不到一半就死** |
| 融合前置同基础 | 无我之境、不死魔身永远合不出来（一个基础只能选一条分支） |
| 道人融合要通用法术 | 需要焚山煮海 / 万里冰封 / 万木缚，他学不到 |
| 升级曲线 100×N^1.6 | 满级要 131 小时，和"20-40 小时"差五倍 |
| 敌人数和刷怪间隔矛盾 | 90 秒 / 3 秒 = 30 只，表里写 8 只 |
| 没有存档结构 | 三个角色独立这件事在代码里没有落点 |

### 三条"只看单次、不看总量"栽过的坑

```
剑客消耗 0%   → 违反设计底线（无代价变强）
剑客消耗 2%   → 一关 120 次 × 2% = 240%，打不到一半就死
剑客消耗 0.2% → 一关 120 次 × 0.2% = 24%，结束还剩 1/3 血  ✅
```

**`systems.md` 里的「气血预算」就是为这个写的。**
以后加任何自伤技能，都要先乘一遍出手次数。
