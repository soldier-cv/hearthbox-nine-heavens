# 九霄 · 玩法一页纸

## 一句话

三个修士，一座被灭门的山。每个人都往上走，每个人都想知道点什么。

## 核心动词

**进化**

不是"打怪"，不是"躲避"。每一局的核心决策是：**这条路该往哪个方向走下去**。

打怪是燃料。故事是理由。

## 四层结构

```
三个角色        剑客 / 道人 / 魔头        ← 你是谁，为什么上山
      ↓
关外等级 1-30    修为、功法解锁          ← 长线成长
      ↓
关内等级 0 起    道行、三选一            ← 一局的爆发
      ↓
九关情节        乱葬岗 → 九霄            ← 你为什么打
```

**由外到内，一层比一层短。** 最外层是几十小时，最内层是 25 分钟。

## 三个角色

| | 剑客 · 陆青锋 | 道人 · 无尘 | 魔头 · 血衣 |
|---|---|---|---|
| 身份 | 山门外门守山人 | 云游散修 | 逃来的魔修 |
| 动机 | 师门被灭，要问一句为什么 | 受垂死者所托 | 想找残经止血 |
| 资源 | 气血 | 灵力 | 气血 + 魔气 |
| 代价 | 施法烧自己的血 | 等灵力 | 入魔掉血 |
| 故事结局 | 知道真相 | 送人归山 | 止住自己的血 |

**三者的等级、修为、功法、剧情、关卡进度全部独立。** 只有"仙缘"共享。

## 两层等级（最关键的设计）

### 关外等级（持久）

```
1-30 级，靠修为提升
每次通关给修为
修为点自己分配：气血 / 伤害 / 冷却 / …
不重置
```

### 关内等级（临时）

```
每局从 0 开始
靠击杀得道行
满了三选一
退出关卡就清空
```

**关外给起点，关内给这一局的表现。**

| | 关外 5 级 | 关外 15 级 |
|---|---|---|
| 进关卡气血 | 140 | 240 |
| 起始剑意上限 | 4 层 | 8 层 |
| 开局技能等级 | 1 级 | 3 级 |
| 关内还能升 | 12 次 | 12 次（一样） |

**关内永远约 12 次升级**，不管关外多高。否则高等级会滚雪球，关卡失去意义。

## 第一分钟

1. 选角色（只有剑客可选，另两个要解锁）
2. 进第一关：乱葬岗
3. 三具腐尸慢慢围过来，青锋式一剑砍倒
4. 地上掉一块道行碎片
5. 道行满了，弹出三选一：**强化青锋式 / 学会回风斩 / 气血 +20**

**第一分钟必须看到两件事**：这条路的代价是什么（烧血），以及"打怪能让你变强"。

## 和同类游戏的区别

| | 吸血鬼幸存者 | 哈迪斯 | 九霄 |
|---|---|---|---|
| 核心循环 | 自动打，玩家走位 | 房间推进 + 对话 | 闯关 + 角色养成 |
| 变强方式 | 武器升级 | 祝福组合 | 关外修为 + 关内三选一 |
| 角色 | 一个 | 一个（换武器） | **三个，各自独立** |
| 叙事 | 弱 | 强（反复死亡推进） | 强（三段交叉的故事） |
| 代价 | 无 | 无 | **每个角色都在付出** |

**最关键的区别**：三个角色不是"三个职业"，是**三种代价**。

剑客烧血、道人等灵力、魔头在流血。

## 不做什么

- **不做联机**
- **不做装备系统**（只有功法）
- **不做炼丹炼器**
- **不做支线**（一条主线九关，三个视角）
- **不做多结局**（三个角色各一个结局，没有"真结局"）
- **不做 3D**
- **不做角色自定义**（三个角色是写死的，不是捏人）
