# 九霄 · 玩法一页纸

## 一句话

一个散修从山门废墟出发，一路打到九霄之上。路上靠修炼三部体系变强，把法术进化成更强的形态，也一路看清自己是谁。

## 核心动词

**进化**

不是"打怪"，不是"躲避"。每一局的核心决策是：**这条路该往哪个方向走下去**。

打怪只是燃料。故事只是理由。

## 三层结构

```
修炼三部（剑修 / 法修 / 魔修）   ← 决定你用什么代价变强
      ↓
法术进化（基础 → 进阶 → 融合）    ← 决定你怎么打
      ↓
九关情节（乱葬岗 → 九霄）         ← 决定你为什么打
```

三者叠在一起才是一款游戏，缺一样都不成立。

## 第一分钟

1. 乱葬岗，一盏残灯
2. 选一个修炼路线（剑 / 法 / 魔），三张卡
3. 选两个起手技能
4. 腐尸慢慢围过来，青锋式一剑砍倒
5. 地上掉一块**道行碎片**
6. 道行满了，弹出三选一：**强化青锋式 / 学会回风斩 / 气血 +20**

**第一分钟必须让人看到两件事**：这条路选了什么（流派），以及"打怪能让你变强"（进化）。

## 和同类游戏的区别

| | 吸血鬼幸存者 | 哈迪斯 | 九霄 |
|---|---|---|---|
| 核心循环 | 自动打，玩家走位 | 房间推进 + 对话 | 闯关 + 三部修炼 |
| 变强方式 | 武器升级 | 祝福组合 | 三部体系 + 法术融合 |
| 叙事 | 弱 | 强（反复死亡推进剧情） | 强（九关一条线） |
| 代价 | 无 | 无 | **每条路都有代价** |

**最关键的区别**：九霄的每一条修炼路线都在**付出东西**。

- 剑修烧气血
- 法修等灵力
- 魔修在流血

这是设计核心。不是"选一个更强的"，是"选一个你愿意付的代价"。

## 不做什么

这一版明确**不做**：

- **不做联机**
- **不做装备系统**（只有功法，没有武器防具）
- **不做炼丹炼器**
- **不做多角色**（一个无名修士，差异靠流派）
- **不做 3D**
- **不做支线**（一条主线九关）
- **不做多结局**（现在只有"走进去"）
