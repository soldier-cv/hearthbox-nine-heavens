# 九霄 · 玩法一页纸

## 一句话

一个修士从山门出发，一关一关往上打，靠收集功法碎片把法术进化成更强的形态，撑到九霄之巅。

## 核心动词

**进化**

不是"打怪"，也不是"躲避"。玩家每一局做的核心决策是：**这个法术该往哪个方向进化**。

打怪只是进化的燃料。躲只是活下去的手段。

## 修仙的世界观怎么变成关卡

修仙小说的核心结构是"境界递进"：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。

这天然就是 Roguelike 的九层结构：

| 层 | 境界 | 场景 | 关卡机制（对应修仙设定） |
|---|---|---|---|
| 1 | 炼气 | 山门外的野林 | 妖兽零散，教你走位与出手 |
| 2 | 筑基 | 灵脉洞窟 | 地形收窄，逼迫近身 |
| 3 | 金丹 | 废弃丹房 | 场上出现毒雾，考验持续伤害应对 |
| 4 | 元婴 | 万剑冢 | 剑阵定期扫过，考验闪避节奏 |
| 5 | 化神 | 心魔幻境 | 画面变灰，敌人变成你的影子 |
| 6 | 炼虚 | 虚空裂隙 | 地面时有时无，考验位移 |
| 7 | 合体 | 双生道场 | 两个敌人共享生命，要同时压制 |
| 8 | 大乘 | 天雷台 | 落雷不断，考验资源管理 |
| 9 | 渡劫 | 九霄之巅 | 天劫本体，把所有机制叠起来 |

**每三层是一个大境界**，过第三、六层时给一次"大机缘"（三选一带稀有词条），对应小说里的突破。

九层打完约 25 分钟。每次跑图会从 9 层里抽 6 层，顺序基本保持，中间可以跳过一层——这是 Roguelike 的跑图随机性，也是让 25 分钟不至于太长。

## 八个字段

| 项 | 内容 |
|---|---|
| 核心动词 | 进化 |
| 玩家在做什么 | 一边躲一边打，把法术往某个方向叠，凑出组合 |
| 失败条件 | 气血归零 |
| 成功条件 | 打完第九层 |
| 一局时长 | 约 25 分钟（第一次玩会更久） |
| 需要几个键 | 1 个攻击键 + 方向 + 1 个闪避键 |
| 是否需要鼠标 | 不需要 |
| 一句话卖点 | 掌心雷修满之后，能变成九霄天雷 |

## 第一分钟

1. 山门外，一个木桩妖兽慢慢走过来
2. 按下攻击键，掌心雷自动打出去
3. 打死第一个，地上掉一个发光碎片
4. 走过去碰到碎片，右上角"掌心雷 1/5"
5. 打到第五个，弹出三张卡：**雷势（伤害+）**、**迅雷（冷却-）**、**引雷（射程+）**
6. 选一张，法术明显变强了

**第一分钟就要让人看到"进化"这个动词**，不是先打十分钟怪。

## 操作检查

- [x] 只需要 `ctx.input.p1`（手柄层）就能玩——攻击、闪避、移动全在方向键与两个键上
- [x] 不需要鼠标
- [x] 一个没玩过的人看截图能猜出是"打怪 + 收集"

## 不做什么

这一版明确**不做**：

- **不做联机**。单机跑图，存档在本地
- **不做剧情对话**。世界观靠关卡名、敌人形态、法术名传达，不写对白
- **不做装备系统**。只有功法，没有武器防具
- **不做角色选择**。所有人从同一个修士开始，差异化靠流派
- **不做炼丹/炼器/宗门**。这些是 IP 的延伸，不是这一版的核心
- **不做 3D**。2D 俯视角，像素风

## 和同类游戏的区别

| | 吸血鬼幸存者 | 九霄 |
|---|---|---|
| 核心循环 | 武器自动打，玩家只管走位 | 玩家主动出手，走位与时机都重要 |
| 进化方式 | 武器 + 被动凑满升级 | **两个法术合体**，产生新法术 |
| 关卡 | 一张图无限刷 | 九层递进，每层换机制 |
| 主题 | 通用奇幻 | 修仙，法术有明确的境界感 |
