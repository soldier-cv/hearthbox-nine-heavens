# 术语

> 玩家看到的字，和代码里的名字不是一回事。
>
> 代码里可以叫 `outer` / `run` / `offer`，**界面上不许出现这些词**。
> 界面上每一句都要能放进一个中国古代修仙故事里。

## 对照表

| 代码里 | 界面上 | 为什么 |
|---|---|---|
| `outer` / 关外等级 | **道基 N 重** | "关外"在中文里指塞外，和"关卡之外"撞车；道基是修仙里现成的说法 |
| `run` / 关内 | 不出现 | 玩家不需要知道"一局"这个概念，他只知道这一趟上山 |
| `offer` / 三选一 | **参悟** | 三选一是开发术语。参悟是修士拿到法门时的动作 |
| `branch` / 二选一 | **择路** | 不可逆的选择，得有个不可逆的词 |
| 天资（掷骰） | **测天资**（三块测灵石，择其一） | 骰子是桌面游戏的东西；测灵石是修仙里的东西，而且"三块择优"比"反复重掷"更像机缘 |
| `tier` / Boss | 不出现 | 分档数值不进界面；真要称呼就是"妖将""大妖" |
| 首通 / 重刷 | **初入 / 再入** | 同一处秘境可以再进去，不是"重刷副本" |
| `hit` / 攻击键 | **出手** | 修士不出"攻击"，出手就是斗法 |
| 菜单确认 | **J 确认 / K 定下** | 直接写键名，比"攻击键"少一层翻译 |
| 死亡 | **道消** | 已有，保留 |
| 通关 | **飞升** | 已有，保留 |

## 三条硬规矩

1. **界面上不出现英文、不出现"等级/经验值/血条/伤害数字"这类网游词。**
   气血、灵力、道行、修为、境界——用这套。
2. **境界跟位置走**（第 N 关 = 第 N 境），**道基跟修为走**（道基 1~30 重）。
   两者不是一个东西，界面上不能混着叫。
3. **新加一句文案，先问：这句话放进《凡人修仙传》里违和吗？** 违和就换。
