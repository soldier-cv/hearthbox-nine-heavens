# 技能与进化系统

> 这份文档是整个游戏的核心。技能怎么进化、怎么组合、流派怎么成型，全在这里定死。

## 1. 三层结构

```
基础法术（6 个）      每个能升 5 级
      ↓ 修满 5 级
进阶形态（每法术 2 个分支）
      ↓ 两个进阶形态合体
融合法术（跨法术组合）
```

举例：

```
掌心雷（1-5 级）
  ├─ 修满后选「雷势」→ 五雷正法（范围伤害）
  └─ 修满后选「迅雷」→ 疾电诀（高频单体）
                        ↓
              五雷正法 + 焚天印 → 九霄天雷
```

**关键点：进阶形态是二选一，不可逆。** 这是流派分化的起点——你选了雷势就走不了迅雷。

## 2. 六个基础法术

每个法术对应一个修仙流派的方向。**一局最多带 3 个**，装不下所有东西，所以必须取舍。

| 法术 | 属性 | 定位 | 修满后的两条路 |
|---|---|---|---|
| **掌心雷** | 雷 | 中距离单体，起手技 | 雷势→五雷正法（范围）<br>迅雷→疾电诀（高频） |
| **焚天印** | 火 | 近身范围，持续灼烧 | 爆炎→焚山煮海（大范围爆炸）<br>烬火→不灭心火（灼烧不灭） |
| **玄冰诀** | 冰 | 减速控制，伤害低 | 凝霜→万里冰封（冻结）<br>碎冰→千刃冰棱（碎片溅射） |
| **青木诀** | 木 | 召唤藤蔓，限制走位 | 缠绕→万木缚（定身）<br>生机→回春藤（回血） |
| **金身诀** | 金 | 自身强化，护体 | 铁壁→不动明王（免伤）<br>锐金→金刚破（反伤） |
| **御风术** | 风 | 位移与闪避 | 疾风→踏风而行（持续加速）<br>旋风→风卷残云（吸附敌人） |

**为什么是这六个**：雷火冰是伤害三要素，木是控制与恢复，金是防御，风是机动。六边形覆盖了所有玩法需求，任选三个都能组出可用流派。

## 3. 技能进化：三级台阶

### 第一级：基础升级（1→5 级）

每个法术收集同名碎片升级。碎片从敌人身上掉，也可以从关卡宝箱拿。

| 等级 | 效果 |
|---|---|
| 1 | 学会该法术，基础伤害 |
| 2 | 伤害 +20% |
| 3 | 解锁一个次要效果（如掌心雷开始有麻痹） |
| 4 | 伤害再 +20%，冷却 -10% |
| 5 | **修满**，可以选进阶分支 |

**5 级之后不再升这个法术**，必须选分支。

### 第二级：进阶分支（二选一，不可逆）

修满时弹出两张卡，选一张。**这是本局唯一一次不可逆选择**，之后这个法术的形态就固定了。

分支不只是数值差异，是**玩法差异**：

- 五雷正法：打一片，但冷却长
- 疾电诀：打得快，但单发弱

### 第三级：融合（跨法术组合）

问题："掌心雷修满之后，怎么变成九霄天雷？"

**答案：需要另一个法术的进阶形态作为素材。**

| 融合产物 | 前置 A | 前置 B | 效果 |
|---|---|---|---|
| **九霄天雷** | 五雷正法 | 焚山煮海 | 全场落雷，带灼烧 |
| **天霜雷狱** | 疾电诀 | 万里冰封 | 连锁闪电，冻结传导 |
| **青莲雷火** | 五雷正法 | 万木缚 | 雷击定身，范围持续 |
| **不动雷音** | 五雷正法 | 不动明王 | 被击时自动反击雷 |
| **焚天冰狱** | 焚山煮海 | 万里冰封 | 冰火双环，交替伤害 |
| **枯木逢春** | 不灭心火 | 回春藤 | 灼烧转化为治疗 |
| **风雷引** | 疾电诀 | 风卷残云 | 雷随移动轨迹 |
| **金刚怒目** | 金刚破 | 焚山煮海 | 受击反伤带爆炸 |

**融合规则**：

1. 两个前置都必须是**进阶形态**（修满 + 选了分支）
2. 融合后**两个前置法术消失**，换成融合法术（占一个技能栏）
3. 融合是**可选**的，不融合也能通关
4. 融合后有独立的升级路线（3 级）

**这解决了什么问题**：普通 Roguelike 的"组合"只是数值叠加。这里是**质变**——你牺牲两个法术，换一个更强的。这个取舍就是流派。

## 4. 流派设计

流派不是预设的，是**从选择里长出来的**。以下五个是设计上验证过能成立的，但玩家可能组出别的。

### 流派一：雷主（爆发流）

```
掌心雷 → 五雷正法 → 九霄天雷
   ↑
焚天印 → 焚山煮海
```

**打法**：站在远处放雷，敌人聚堆时一个天雷清场。近身就闪。

**优势**：清场能力强，打大群舒服
**弱点**：冷却长，被贴身很难受
**需要**：御风术保命，或者金身诀扛一下

### 流派二：冰控（控场流）

```
玄冰诀 → 万里冰封 → 天霜雷狱
   ↑
掌心雷 → 疾电诀
```

**打法**：先冻住，再连锁电。敌人几乎动不了。

**优势**：安全，容错高
**弱点**：伤害偏低，打得慢，容易被拖
**需要**：输出补足，或者靠时间磨

### 流派三：木火（持续伤害流）

```
焚天印 → 不灭心火 → 枯木逢春
   ↑
青木诀 → 回春藤
```

**打法**：挂灼烧，靠回血磨。打得慢但几乎不死。

**优势**：续航极强，新手友好
**弱点**：爆发乏力，打 Boss 会超时
**需要**：至少一个爆发法术

### 流派四：金身（反伤流）

```
金身诀 → 不动明王 → 不动雷音
   ↑
掌心雷 → 五雷正法
```

**打法**：主动挨打，靠反伤与自动反击输出。

**优势**：不需要操作，站着就赢
**弱点**：前期弱，要撑到融合
**需要**：血量上限

### 流派五：御风（高速流）

```
御风术 → 踏风而行 → 风雷引
   ↑
掌心雷 → 疾电诀
```

**打法**：不停移动，靠移动轨迹放雷。不站桩。

**优势**：机动性最高，几乎不被摸到
**弱点**：需要持续操作，累；停下就废
**需要**：手速

### 流派之间的关系

```
        雷主（爆发）
             ↑
   冰控 ←  ─  ─  → 木火（续航）
             ↓
        金身（防御）         御风（机动）
```

五个流派各有克制：雷主怕贴身，冰控怕耗时，木火怕爆发不够，金身怕前期，御风怕站定。

**没有最强流派**，这是设计目标。如果有，就是数值没调好。

## 5. 法术池与抽取

每局开始时随机给 **2 个**基础法术（三选一，选两个）。

之后击杀精英怪、开宝箱、升级时都能拿到碎片或新法术。

**抽取规则**：

| 来源 | 给什么 |
|---|---|
| 普通怪 | 30% 掉当前法术的碎片 |
| 精英怪 | 必掉碎片，20% 掉新法术 |
| 宝箱 | 50% 碎片，30% 新法术，20% 属性 |
| 过关 | 三选一（碎片 / 新法术 / 属性） |

**法术栏只有 3 格**。拿到第 4 个法术时要丢弃一个——这是强制的取舍点。

## 6. 数值框架

具体的数字写在 `systems.md`，这里只定框架。

**伤害计算**：

```
最终伤害 = 基础伤害 × 等级倍率 × 进阶倍率 × 属性加成 × 随机浮动(0.9~1.1)
```

**冷却计算**：

```
实际冷却 = 基础冷却 / (1 + 冷却缩减)
```

**为什么用除法而不是减法**：减法叠加到 100% 会让冷却变成 0，之后就没意义了。除法永远不会到 0。

## 7. 平衡检查清单

设计任何一个法术，都要能回答：

- [ ] 它的一级有什么用？（不能是"满级才强"）
- [ ] 它的两个分支分别适合什么流派？
- [ ] 它能和谁融合？融合后的定位是什么？
- [ ] 没有它，哪些流派会不成立？
- [ ] 有它，会不会让某个流派过强？

**如果五个问题有一个答不上来，这个法术不该进池子。**

## 8. 还没定的

诚实列出来：

1. **融合后能不能再融合？** 现在计划只做一层。两层会让组合爆炸（8 × 8 = 64 种），超出独立开发的范围。
2. **同一法术能不能重复拿？** 现在设计是不能，拿满就进分支。如果允许重复，升级节奏会乱。
3. **流派平衡怎么测？** 没有真玩家。计划是自己用五个流派各通一遍，看时间是否接近。
4. **融合素材的稀有度**：现在所有进阶形态都能融合，可以让玩家一直等融合。是否要限制每局最多两次融合？
