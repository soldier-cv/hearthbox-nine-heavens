# 法术与技能进化

> 上一版只设计了法修一路。现在改成**三部各有自己的技能树**，
> 融合可以跨部，但跨部融合是稀有的。

## 三层结构

```
初始技能（每部 3 个，选 2 个）
      ↓ 吃道行升到 5 级
进阶分支（每技能 2 条，二选一，不可逆）
      ↓ 两条分支凑齐
融合（同部常见，跨部稀有）
```

## 跨部融合（稀有）

三部之间也能融合，但需要特定组合，且**只能发生一次**（占满所有技能栏）。

| 融合 | 前置（跨部） | 效果 |
|---|---|---|
| **剑心通明** | 刹那（剑）+ 九幽雷（法） | 闪到背后时落雷 |
| **血剑** | 血刃（剑）+ 万毒噬心（魔） | 伤害带流血，流血可传染 |
| **天魔解体** | 魔域（魔）+ 御风（法） | 范围内加速自己、减速敌人 |
| **剑魔合一** | 无我之境（剑）+ 不死魔身（魔） | 背后暴击吸血 |

**为什么跨部稀有**：跨部融合会让"三部的代价"模糊——你既烧血又来灵力，就不痛了。

所以跨部融合**只给一种极端玩法**，不给主流。

## 道行与升级

道行是唯一的升级资源，不再叫"碎片"（那是旧设计的说法）。

```
每次三选一：
  强化现有技能 40%
  新技能      25%
  属性        25%
  稀有词条    10%
```

详见 `resources.md`。

## 融合触发

融合不是攒够就自动合，而是**过关时弹出**：

1. 过关进入三选一
2. 如果检测到可融合的组合，**优先显示融合选项**
3. 玩家可以选融合，也可以不选（选其他三个）

**为什么让玩家选**：两个技能换一个，是重决定，不能自动。

## 技能的"代价"必须写进技能本身

| 部 | 代价体现在哪 |
|---|---|
| 剑修 | 技能消耗气血 |
| 法修 | 技能消耗灵力，冷却长 |
| 魔修 | 技能累加魔气，入魔掉血 |

**如果一个技能零消耗，它就违反了设计原则。** 检查清单里要过这一条。

## 还没定的

1. **三部能不能混修？** 现在设计是不能。混修会让代价体系失效。
2. **建技能栏几格？** 现在 3 格。三部各自只有 3 个初始技能，选 2 个，加 1 格给融合。
3. **跨部融合怎么触发？** 现在设计是"隐藏组合"，玩家不查攻略发现不了。可能要给出提示。
4. **稀有词条池**：现在列了 8 条，不够。至少要 20 条才不会重复。
