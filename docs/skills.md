# 技能与进化

> 三个角色各有自己的技能树。融合同角色内常见，跨角色稀有。
>
> 技能的具体数值见 `characters.md`，这份只讲结构和规则。

## 三层结构

```
初始技能（每个角色 3 个，选 2 个）
      ↓ 吃道行升到 5 级
进阶分支（每技能 2 条，二选一，不可逆）
      ↓ 两条分支凑齐
融合（同角色常见，跨角色稀有）
```

## 跨角色融合（稀有）

需要特定组合，且**一局只能发生一次**。

| 融合 | 前置（跨角色） | 效果 |
|---|---|---|
| **剑心通明** | 刹那（剑客）+ 九幽雷（道人） | 闪到背后时落雷 |
| **血剑** | 血刃（剑客）+ 万毒噬心（魔头） | 伤害带流血，可传染 |
| **天魔解体** | 魔域（魔头）+ 御风（道人） | 范围内加速自己、减速敌人 |
| **剑魔合一** | 无我之境（剑客）+ 不死魔身（魔头） | 背后暴击吸血 |

**为什么跨角色稀有**：跨角色融合会让"代价"模糊——你既烧血又来灵力，
就不痛了。所以跨角色融合**只给一种极端玩法**，不给主流。

**实现前提**：跨角色融合需要玩家在同一局里拿到别的角色的技能。
这只有在"关外等级高到解锁跨角色技能"时才可能。见 `resources.md`。

## 道行与升级

道行是关内唯一的升级资源。

```
每次三选一：
  强化现有技能 40%
  新技能      25%
  属性        25%
  稀有词条    10%
```

详见 `resources.md`。

## 融合触发

融合不是攒够就自动合，而是**过关时弹出**：

1. 过关进入三选一
2. 检测到可融合组合时，**优先显示融合选项**
3. 玩家可以选融合，也可以不选

**为什么让玩家选**：两个技能换一个，是重决定，不能自动。

## 技能的"代价"必须写在技能本身

| 角色 | 代价体现在哪 |
|---|---|
| 剑客 | 技能消耗气血 |
| 道人 | 技能消耗灵力，冷却长 |
| 魔头 | 技能累加魔气，入魔掉血 |

**如果一个技能零消耗，它就违反了设计原则。**

## 功法解锁是关卡外的

技能不是一开始全有。关外等级决定能带哪些进关卡：

| 关外等级 | 可带 |
|---|---|
| 1 | 3 个初始技能 |
| 5 | 第 1 条分支 |
| 10 | 第 2 条分支 |
| 15 | 第一条融合 |
| 20 | 第二条融合 |
| 25 | 跨角色融合 |
| 30 | 终极形态 |

**关外解锁的是"可选池"，关内还是只能带 2-3 个。**
