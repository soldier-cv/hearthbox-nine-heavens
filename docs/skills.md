# 技能与进化

> 三个角色各有自己的技能树。**每条分支只能选一个，选了不能反悔。**
>
> 数值换算见 `systems.md`（一击 = 基数 × 括号）。这份只讲结构和规则。

## 三层结构

```
初始技能（每个角色 3 个，选 2 个）
      ↓ 吃道行升到 5 级
进阶分支（每技能 2 条，二选一，不可逆）
      ↓ 两个不同基础技能的已选分支凑齐
融合（同角色内，3 条）

一局最多 2 个基础技能 → 最多 2 条分支 → 最多 1 条融合
```

**注意这条推论**：一局只带 2 个基础技能，每个选 1 条分支，
所以**一局最多只能合成 1 条融合**。

那为什么每个角色写 3 条融合？因为**三条流是三选一**——
玩家这一局走的是哪条流，取决于他开局选的两个技能、和两次分支选择。

```
开局选 青锋式 + 回风斩 → 分支选 断岳式 + 罡风诀 → 万剑归宗（剑主流）
开局选 青锋式 + 回风斩 → 分支选 追风剑 + 血刃   → 血色残阳（残血剑流）
开局选 青锋式 + 守元式 → 分支选 追风剑 + 刹那   → 无我之境（无我流）
```

**三条流不是三条都要走，是一局只能走一条。** 这是 rougelike 的重开价值。

## 一条硬规则：融合的两个前置必须来自不同基础技能

因为「一个基础技能只能选一条分支」，同一技能的两条分支不可能同时在手。
旧文档有三条融合违反了这条（见文末「已修正的矛盾」）。

## 剑客技能树

| 初始 | 分支 A | 分支 B |
|---|---|---|
| 青锋式 | 断岳式（蓄力重击） | 追风剑（三段连击） |
| 回风斩 | 罡风诀（大范围击退） | 血刃（越残越强） |
| 守元式 | 金刚身（格挡反弹） | 刹那（闪到背后） |

### 剑客融合

| 融合 | 前置 | 效果 |
|---|---|---|
| 万剑归宗 | 断岳式 + 罡风诀 | 全场飞剑，每把独立结算 |
| 血色残阳 | 血刃 + 追风剑 | 每段连击按损失气血加成 |
| 无我之境 | 刹那 + 追风剑 | 闪到背后立刻三段，背后必暴击 |

|---|---|---|

### 道人融合

| 融合 | 前置 | 效果 |
|---|---|---|
| **九霄天雷** | 五雷正法 + 贯日指 | 一线贯穿，沿途落雷 |
| 天霜雷狱 | 九幽雷 + 缩地成寸 | 雷落在你刚离开的位置，定身 |

（焚山煮海 / 万里冰封 / 万木缚 属于旧的通用法术池，道人身上没有）。
现在的六条分支全在树内，两两组合正好三条。

|---|---|---|

| 不死魔身 | 吸血魔功 + 万毒噬心 | 吸血时把一部分伤害转成持续伤害叠层 |

## 九条流（三个角色 × 三条流）

**一局只能走一条流。** 每条流都需要 2 个基础技能 + 各选 1 条分支：

| 流 | 需要的基础技能 | 分支 | 融合 |
|---|---|---|---|
| 剑主 | 青锋式 + 回风斩 | 断岳式 + 罡风诀 | 万剑归宗 |
| 残血剑 | 青锋式 + 回风斩 | 追风剑 + 血刃 | 血色残阳 |
| 无我 | 青锋式 + 守元式 | 追风剑 + 刹那 | 无我之境 |
| 雷主 | 气指 + 引雷符 | 贯日指 + 五雷正法 | 九霄天雷 |
| 雷狱 | 引雷符 + 轻身诀 | 九幽雷 + 缩地成寸 | 天霜雷狱 |
| 风雷 | 气指 + 轻身诀 | 连珠指 + 御风 | 风雷引 |
| 毒魔 | 血咒 + 魔影 | 万毒噬心 + 影分身 | 血海滔天 |
| 吸魔 | 噬魂 + 血咒 | 吸血魔功 + 万毒噬心 | 不死魔身 |
| 魔染 | 血咒 + 魔影 | 血爆 + 魔域 | 魔染 |

**注意毒魔和魔染用的是同一对基础技能。** 这是唯一一处：
血咒 + 魔影 这一对，选不同分支会走向两条完全不同的流。
**这是整个技能树里最深的一次选择。**

### 为什么一局只能一条流

```
一局带 2 个基础技能
每个基础技能只能选 1 条分支（不可逆）
2 条分支 → 刚好凑成 1 条融合
```

这是数学，不是设计选择。**九条流是三次重开的选择空间，不是一局的目标。**

### 三条流各给一种"代价换什么"的答案

| 流 | 付出 | 换来 |
|---|---|---|
| 剑主 | 攒剑意时不能挨打 | 一发清场 |
| 残血剑 | 主动掉血 | 越残越强 |
| 无我 | 贴脸（最危险的距离） | 背后必暴击 |
| 雷主 | 一发要攒满灵力 | 一线贯穿 |
| 雷狱 | 放雷后必须闪走 | 敌人踩在你刚离开的地方 |
| 风雷 | 精度（三发可能打空） | 频率 |
| 毒魔 | 时间（毒是慢的） | 总量 |
| 吸魔 | 气血上限（换续航） | 越打越厚 |
| 魔染 | 层数（要先叠） | 引爆回血 |

**没有一种流是"纯加成"。**

## 道行与升级

道行是关内唯一的升级资源。

```
每次三选一：
  强化现有技能 40%
  新技能      25%
  属性        25%
  稀有词条    10%
```

详见 `systems.md`。

## 融合触发

融合不是攒够就自动合，而是**过关时弹出**：

1. 过关进入三选一
2. 检测到可融合组合时，**作为三张卡之一出现**（不是自动替换）
3. 玩家可以选融合，也可以选别的

**为什么让玩家选**：两个技能换一个，是重决定，不能自动。

**融合后技能栏位**：两个前置基础技能合为一个融合技能，**腾出一个栏位**。
融合技能可以继续吃道行升到 3 级。

**重要**：融合之后，那两个基础技能就没了。下一关要重新累积。
所以融合的时机是关键决策——早融合早爽，但早期融合会失去两个技能
的成长空间。**这是"进化"这个核心动词最实质的一次选择。**

## 融不了的情况

如果玩家一局只选了 1 个基础技能（比如第二个技能一直没出），
他永远合不成融合。这时三选一里应该多给"新技能"的权重。

**实现要点**：三选一的权重不是固定的 40/25/25/10，
要按玩家当前状态调整：

| 玩家状态 | 调整 |
|---|---|
| 只有 1 个基础技能 | 新技能权重 25% → 60% |
| 有两个基础技能但都还没分支 | 分支不出，只出强化和属性 |
| 有一条分支但没配对 | 新技能权重提到 45%（逼他补第二个） |
| 已有配对 | 融合权重 20% |

**这条不做，玩家会遇到"这一局就是合不出来"的挫败。**
这是 rougelike 最常见的失败设计。

## 技能的"代价"必须写在技能本身

| 角色 | 代价体现在哪 |
|---|---|
| 剑客 | 技能消耗气血（2~4%），包括平砍 |
| 道人 | 技能消耗灵力，灵力是配额不是冷却 |
| 魔头 | 技能累加魔气，入魔掉血 |

**如果一个技能零消耗，它就违反了设计原则。**

## 功法谱（关外）

技能不是一开始全有。**用悟道点在功法谱上买，买过的才会出现在这一局的三选一里。**

| 功法 | 单价（悟道点） | 买了之后 |
|---|---|---|
| 初始功法（3 门） | 免费 | 开局三选二 |
| 进阶分支（6 条） | 2 点 / 条 | 这个基础技能 5 级时，这条分支会进分支二选一 |
| 融合（3 条） | 3 点 / 条 | 两个前置都在手时，融合会进三选一 |
| 被动功法（3 条） | 2 点 / 条 | 进关即生效，不占技能槽 |

**买功法 = 改这一角色的卡池。** 没买的永远抽不到。

| 角色 | 被动功法 |
|---|---|
| 剑客 | 剑心（暴击 +8%）、炼体（气血上限 +10%）、血食（击杀回血 +0.7%） |
| 道人 | 气海（灵力上限 +30）、澄心（冷却 −10%）、引气（灵力回复 +50%） |
| 魔头 | 魔威（伤害 +8%）、魔骨（气血上限 +10%）、血食（击杀回血 +0.7%） |

**为什么功法要花点买，不能按等级白送**：
白送的话，30 级时每个人的卡池都一样，关外就只剩数值。
用点买，玩家必须决定"我要走哪条流"——而这正是九条流存在的意义。

**一局还是只带 2 个基础技能 + 融合后的空位**，功法谱扩大的是"可选池"，不是"能带的数量"。


## 已修正的矛盾

写代码之前必须先知道这几处文档互相打架，现在全部按下面这版为准：

| 问题 | 旧写法 | 现在 |
|---|---|---|
| 技能池 | `src/skills.ts` 是六系通用池（掌心雷/焚天印/玄冰诀/青木诀/金身诀/御风术），所有角色共用 | 每个角色 3 个专属初始技能，没有通用池 |
| 道人融合 | 需要焚山煮海 / 万里冰封 / 万木缚（他学不到） | 全部换成他树内的分支 |
| 剑客消耗 | 三个技能全写 `0` | 气血 0.2~0.4%（一关出手 120 次，总共 24%） |
| 剑客·无我之境 | 刹那 + 金刚身（同属守元式，不可能） | 刹那 + 追风剑 |
| 魔头·不死魔身 | 吸血魔功 + 夺舍（同属噬魂，不可能） | 吸血魔功 + 万毒噬心 |
| 跨角色融合 | "在同一局里拿到别的角色的技能" | **删除。** 与"三个角色进度独立"冲突 |
| 技能栏 | "3 格：2 个初始 + 1 个融合位" | 2 个基础位 + 融合后腾出的位 |

### 关于被删掉的跨角色融合

旧版列了四条（剑心通明 / 血剑 / 天魔解体 / 剑魔合一），需要玩家在一局里
拿到另一个角色的技能。这和两条硬规矩冲突：

1. 三个角色的功法解锁互相独立
2. 一局只玩一个角色

**替代方案**：三个角色各自通关后，每人解锁一个"残经互证"形态——
**用自己的技能，打出另一个人的招式**（例如剑客的万剑归宗里混着雷）。
视觉上是交叉的，机制上还是自己的树。**不引入跨角色依赖。**

## 还没定的

1. **技能栏 2 格够不够**？现在是 2 基础，融合后腾出 1 格（可以再学一个新技能）。
   **一局最多 1 条融合**，这是数学决定的（2 基础 × 1 分支），不是选择。
2. **三选一权重表**（见上一节）的具体数值需要实测。
3. **稀有词条池要多少条**？现在 10 条，想凑 20 条。
4. **同一个技能能不能重复拿**？现在不能，拿满就进分支。
5. **9 条流的 DPS 表**还没做。现在只有技能描述，没法验平衡。
   这是"可以开始写代码"之前的最后一件事。
6. **融合之后两个基础技能真的消失吗**？现在设计是消失。
   如果保留，融合就变成纯加成，失去代价。
