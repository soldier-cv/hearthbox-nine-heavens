# 自动化：让手只用来走位

> 这个游戏的爽点不是"按得准"，是"这一局长成了什么样"。
>
> 所以**出手、拾取、选卡**默认交给系统，玩家只保留两件事：
> **往哪走**、**要不要改主意**。
>
> 所有自动化都可以在设置里关掉，关掉之后行为和手动版完全一致。

## 一条底线

**自动化只替代操作，不替代判断。**

| 交给系统 | 留给玩家 |
|---|---|
| 冷却好了就出手 | 走位、贴脸还是拉开 |
| 掉落物自己飞过来 | 闪避（K / 手柄 B） |
| 升级时按默认路线选卡 | 想换就按方向键改选 |
| 开局按默认顺序选功法 | 想换就按方向键改选 |

**"自动"永远有手动接管的口子，而且接管不需要先关设置。**
玩家一按方向键，系统就停下来等他。

## 一、自动出手

### 规则

```
每个槽独立冷却。冷却归零且付得起代价 -> 立刻对最近的敌人出手。
两个槽同时好了 -> 按槽位顺序，但每次施法至少间隔 0.12 秒。
```

- **不需要按键。** J 仍然保留，作用是"现在立刻再来一发"（补刀、抢击杀）。
- **只打视野内最近的敌人**，不追屏幕外的东西。
- **打不到就不出手。** 没有目标时技能不进冷却，也不扣资源。
- **辅助类技能单独判断**：
  - 格挡 / 护体：身边 70 像素内有敌人才放
  - 位移 / 冲刺：**不自动放**。位移等于放弃站位，必须玩家自己决定

### 为什么位移不自动

自动位移会让玩家在没看懂局面的时候被送到敌人堆里。
"往哪走"是玩家唯一保留的操作，不能被系统抢走。

### 出手节奏

| 项 | 值 | 理由 |
|---|---|---|
| 两次施法最小间隔 | 0.12 秒 | 防止一帧内把三个槽全倒出去，特效糊成一片 |
| 索敌距离 | 技能自身 `range`，下限 110 | 太短会站着不动，太长会打到屏幕外 |
| 无目标时 | 不进冷却、不扣资源 | 否则剑客会站着把血烧光 |

## 二、自动拾取

### 磁吸

```
掉落物进入 76 像素 -> 加速飞向玩家
进入 12 像素 -> 收下
```

磁吸是**加速**不是瞬移：玩家看得见东西被吸过来，才知道自己捡到了什么。

### 三种掉落

| 掉落 | 外观 | 效果 | 掉率（杂兵 / 精怪 / 妖将） |
|---|---|---|---|
| 道行碎片 | 金色碎片 | 给对应技能加 1 碎片，3 片升 1 级 | 40% / 80% / 100% |
| 血珠 | 绿叶 | 回气血上限的 1.5% | 6% / 25% / 60% |
| 灵珠 | 天紫 | 按角色给资源 | 8% / 30% / 60% |

**灵珠按角色换算**（三个角色各一种资源，不能给同一份数值）：

| 角色 | 灵珠给什么 |
|---|---|
| 剑客 | 剑意 +2（不超过上限） |
| 道人 | 灵力 +18 |
| 魔头 | 魔气 −15（还没入魔时才生效） |

**血珠为什么只有 1.5%**：一局约 400 个敌人，全吃约回 12 万，
刚好补上"必须走位"造成的漏吃。多了就变成站着吸血。

**Boss 不按杂兵掉率**：Boss 死一次必掉 3 个血珠 + 1 个灵珠，让残血过关有回报。

### 不自动做的

- **不自动吃场上的机关、香炉、剧情道具**（那些是关卡机制，不是掉落）
- **不自动捡已经满级的技能碎片**（碎片仍然会飞过来，但直接消失，不再占屏）

## 三、自动选卡

### 规则

```
三选一弹出 -> 倒计时 2.2 秒 -> 到点按默认优先级选一张。
倒计时期间按方向键 -> 取消这一次的自动，改成玩家自己选。
按 J -> 立刻确认光标那一张。
```

倒计时画在卡片下方，是一根会变短的横条，玩家看得见"还有多久"。

### 默认优先级

**从高到低**：

```
融合 > 进阶分支 > 新技能 > 强化现有技能 > 稀有词条 > 属性
```

同级的，取列表里靠前的那张。

**为什么融合最优先**：融合是一局里唯一"换形态"的事，错过就要再等一局。
**为什么属性最后**：属性永远拿得到，技能错过就没了。

### 开局选功法

开局三选二也走同一套倒计时：2.2 秒没动，就按列表顺序选两个。
玩家按方向键可以改。

### 自动选卡不是"最优解"

它是**一条能活的默认路线**，不是高手路线。
愿意研究的人按方向键接管；只想看这一局长成什么样的人，让它自己走。

## 四、过场与过关屏

**过场和"过关"这两屏也会自己往下走，4 秒。**

- 过场：读完一屏文字，4 秒后自动进关
- 过关：结算显示完，4 秒后自动开下一关
- **死亡与飞升不自动**：这两屏强制玩家自己按，因为"重来还是退出"是他的决定

**为什么过场要 4 秒而不是跟选卡一样的 2.2 秒**：过场是要读的字，
2 秒还没来得及看清就切走，玩家会以为游戏在抢他的戏。

## 五、设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 自动出手 | 开 | 关掉后回到"按键才出手" |
| 自动拾取 | 开 | 关掉后必须走到掉落物上 |
| 自动推进 | 开 | 三选一、开局选功法、过场、过关自动往下走 |

三项都放在平台的设置面板里（`scope: 'setting'`），
和金手指分开，不影响成就。

**验收时必须两项都试**：全开能一路打到结算，全关能手动打完第一关。

## 参数表

| 项 | 值 | 改之前先想 |
|---|---|---|
| `AUTO.castGap` | 0.12 s | 调小会糊特效，调大会掉 DPS |
| `AUTO.magnetRadius` | 76 px | 调大等于减少走位，风险直接下降 |
| `AUTO.grabRadius` | 12 px | 和玩家碰撞框（8 px）对齐，别调太小 |
| `AUTO.pickDelay` | 2.2 s | 低于 1.2 秒玩家来不及看卡 |
| `AUTO.storyDelay` | 4.0 s | 低于 3 秒过场会读不完 |

**磁吸半径是这套自动化里最危险的一个数。**
它一大，"必须走位"这条底线就被绕过去了。改之前先看 `docs/systems.md` 的承受伤害表。

## 验收

- [ ] 进关后不按 J，技能自己会放，且不会空放（没有目标时不进冷却）
- [ ] 道行碎片、血珠、灵珠都会飞过来，且看得到飞行轨迹
- [ ] 三选一 2.2 秒后自己选一张，横条走完才选
- [ ] 三选一期间按方向键，横条消失，改成手动
- [ ] 过场 4 秒后自己进关，过关 4 秒后自己开下一关
- [ ] 三个设置都关掉后，行为和改版前一致
- [ ] 全程只按方向键，能打完第 1 关
