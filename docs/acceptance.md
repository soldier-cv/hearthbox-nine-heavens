# 验收清单

> `typecheck` 通过不算跑通。改到玩家可见的东西，必须真跑起来并截图。

## 每次改动后的最小检查

```bash
cd ../hearthbox
pnpm dev
```

- [ ] 游戏出现在货架上，名字和简介正确
- [ ] 点进去不是黑屏，没有崩溃页
- [ ] 控制台没有红色报错

## 完整验收（发布前）

### 能玩

- [ ] 键盘能完成一局（方向键 + 动作键）
- [ ] 手柄能完成一局（如果有手柄）
- [ ] 死亡后能重开，不用刷新页面
- [ ] 有明确的开始和结束

### 三个角色

- [ ] 剑客默认可选，道人 / 魔头按条件解锁
- [ ] **练剑客不会让道人变强**（三个存档槽真的独立）
- [ ] 三个角色的关卡顺序不同（第 1 关就该看得出）
- [ ] **同一块地形，三个人的玩法不同**
      （例：乱葬岗 = 剑客守 / 道人不能打 / 魔头围杀）

### 关卡形状

八种形状每种至少有一关能玩通：

- [ ] `HOLD` 守住了才赢，不是杀光了才赢
- [ ] `RUN` 走到出口才赢，不是杀光了才赢
- [ ] `HUNT` 目标会跑，追不上会脱逃
- [ ] `SWARM` 被围住，打出口才能活
- [ ] `TRAP` 机关独立于敌人，有自己的节奏
- [ ] `DUEL` **一个杂兵都不刷**
- [ ] `DUO` 两头都要照顾
- [ ] `SET` 脚本能走完

### 数值

- [ ] **伤害数字是千级起**，不是两位数
- [ ] 杂兵 4 下死、精怪 10 下、妖将 30 下、Boss 60 下
      （随便挑两关验，比值应该一样）
- [ ] 一局能升 12 次三选一，不是 4 次也不是 20 次
- [ ] 通关一次的修为能升 1~2 级关外等级（早期）
- [ ] 满级大约 29 次九关，不是 300 次

### 存档

- [ ] 玩到一半刷新页面，进度还在
- [ ] 关掉标签页再打开，进度还在
- [ ] 换一个游戏再回来，本游戏存档没被串
- [ ] **三个角色各存各的，互不覆盖**
- [ ] 存档带版本号（`v: 1`），旧档能读

### 画面

- [ ] 窗口拉大缩小，画面不变形、不糊
- [ ] 像素风边缘锐利（没有平滑模糊）
- [ ] 文字在 3 米外能看清（如果目标是电视）
- [ ] 没有元素跑到画面外
- [ ] 数字超过 6 位时有缩写（`79.2万`），没有超出卡片

### 性能

- [ ] 连续玩 5 分钟不掉帧
- [ ] DevTools Performance 里单帧 < 16ms
- [ ] 同屏 100 实体时不掉帧
- [ ] 没有内存持续增长（看 Memory 面板）

## 开发顺序（建议）

不要一次做完 27 关。按这个顺序能最快看到"这游戏成不成"：

1. **一个角色、一个形状、一关** —— 剑客 + `HOLD` + 乱葬岗。
   验证：能移动、能打、数字够大、守的东西有意义。
2. **加三选一和道行** —— 验证关内成长的手感。
3. **加通关结算和关外等级** —— 验证两层等级真的分开。
4. **加第二个形状 `RUN`** —— 验证关卡形状能换。
5. **加第二个角色（魔头）的第 1 关** —— 验证"三个角色不一样"这件事成立。
6. 再铺开到九关。

**第 5 步通过之前，不要做第三关。** 如果第 5 步验证不成立，
后面二十多关都是白做。

## 踩坑记录

遇到问题时记在这里，下次不重复踩：

| 现象 | 原因 | 解法 |
|---|---|---|
| 敌人看不见 | 静止敌人（`speed: 0`）生成在屏幕外，它不会走进来 | 静止敌人必须生成在屏幕内 |
| 菜单确认没反应 | 光标停在已选项上，选过的会被拒绝 | 选完自动跳光标 |
| 画面拉伸 | 预览面板是窄高视口，真实 16:9 窗口正常 | 以实际窗口为准 |
| 敌人不往守卫物走 | `HOLD` 关的敌人只朝玩家走 | 敌人必须有"要去的地方" |
| `HUNT` 追不上 | 目标速度 ≥ 玩家速度 | 目标速度只能是玩家的 70~85% |
| `DUO` 打不死 | 回血速度 ≥ 低 DPS 打法 | 回血必须能被最低 DPS 压住 |
| 伤害数字挤成一团 | 千级数值没有缩写 | 6 位以上缩写，战斗飘字不带逗号 |
