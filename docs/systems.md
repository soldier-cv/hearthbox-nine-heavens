## 伤害计算

```
最终伤害 = 基础 × 等级倍率 × 分支倍率 × 资源加成 × 流派加成 × 随机(0.9~1.1)
```

**等级倍率**（1-5 级）：`1.2^(level-1)`
**融合倍率**（1-3 级）：`1.3^(level-1)`

**资源加成**：

- 剑修：`1 + 剑意层数 × 0.04`
- 法修：无（灵力只是门槛）
- 魔修：`1 + 魔气 × 0.005`，入魔时再 ×2

## 冷却

```
实际冷却 = 基础冷却 / (1 + 冷却缩减)
```

用除法不用减法：减法叠加到 100% 会变成 0。

## 帧预算

| 项 | 预算 |
|---|---|
| 逻辑更新 | ≤ 4 ms |
| 绘制 | ≤ 6 ms |
| 同屏实体 | ≤ 100（含子弹与特效） |

**为什么是 100 不是 120**：三部体系下每个敌人可能带状态（灼烧、减速、定身），
状态计算比纯移动贵。保守一点。
