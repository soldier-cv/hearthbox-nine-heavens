# 闯关路线与故事情节

> 参考《西游记》的结构：**一条主线，九个关隘，每一关有名字、有妖怪、有来历**。
>
> 不是随便打九层，是走一条路。

## 主线

你是一个无名散修。山门被毁，师门只剩你一个。

你从废墟里翻出半卷残经，上面只有一句话：

> "欲复山门，需上九霄。九霄之上，有道。"

于是你从山脚出发，一路往上。

## 九个关隘

每关有：地名、守关者、来历、通关后得到什么。

### 第一关 · 乱葬岗（炼气）

| 项 | 内容 |
|---|---|
| 地方 | 山门外的乱葬岗，师兄弟埋在这里 |
| 守关者 | **尸傀**（被邪气污染的师兄弟） |
| 来历 | 灭门那夜，死在这里的人没能入土 |
| 敌人 | 腐尸、噬骨鸦 |
| 通关 | 你不忍下手，但必须过去。最后一具尸傀倒下时，掉出一块山门令牌 |

**情节作用**：开场立情绪。你打的不是杂兵，是同门。

### 第二关 · 断魂涧（筑基）

| 项 | 内容 |
|---|---|
| 地方 | 一道断崖，涧底黑雾 |
| 守关者 | **涧中老蛟** |
| 来历 | 修行千年的蛟，靠吃落崖者修成 |
| 敌人 | 水鬼、毒蛇 |
| 通关 | 蛟死时吐出一枚鳞片，鳞上有前人的剑痕 |

**情节作用**：第一次遇到"比人强的存在"。蛟的鳞片是后面锻造的线索。

### 第三关 · 枯骨庙（金丹）★

| 项 | 内容 |
|---|---|
| 地方 | 半山腰的破庙，供的是不知名的神 |
| 守关者 | **庙中骨佛** |
| 来历 | 有人把整座庙的僧人炼成了一尊佛 |
| 敌人 | 骨僧、香火鬼 |
| 通关 | 佛像碎裂，露出腹中一本《残经·中卷》 |

**情节作用**：第一个大境界突破。残经中卷补全了你的功法，也是"魔修"路线的由来——
书上写着，炼佛的人本也是法修。

### 第四关 · 万剑冢（元婴）

| 项 | 内容 |
|---|---|
| 地方 | 一座全是断剑的山谷 |
| 守关者 | **剑冢守灵** |
| 来历 | 上古剑修大战的战场，死者的剑意不散 |
| 敌人 | 剑灵、无主飞剑 |
| 通关 | 守灵认你为主，送你一柄断剑 |

**情节作用**：剑修的主场。断剑可以修，也可以不修——不修的人后面会少一条路。

### 第五关 · 镜心湖（化神）

| 项 | 内容 |
|---|---|
| 地方 | 湖面如镜，倒映的不是你 |
| 守关者 | **心魔** |
| 来历 | 你自己的影子，映的是你最怕变成的样子 |
| 敌人 | 影分身、妄念 |
| 通关 | 打碎镜子，心魔融入你体内（可选：接受它 = 魔修路线强化） |

**情节作用**：转折点。**接受还是拒绝，决定你后面能不能走魔修的上层。**

### 第六关 · 悬空栈道（炼虚）★

| 项 | 内容 |
|---|---|
| 地方 | 贴在绝壁上的木栈道，很多地方已经断了 |
| 守关者 | **守栈人** |
| 来历 | 他是唯一没被灭门的师叔，守在这里等一个能上来的人 |
| 敌人 | 山魈、坠石 |
| 通关 | 师叔把最后半卷残经给你，然后跳了下去 |

**情节作用**：第二个大境界突破。**这是全篇最重的一场戏**——
你打了六关，以为在打怪，其实在找一个还活着的人。

### 第七关 · 双生洞（合体）

| 项 | 内容 |
|---|---|
| 地方 | 一个洞，两条路，通向同一个地方 |
| 守关者 | **双子道人** |
| 来历 | 一个人修了两套功法，分成了两个人 |
| 敌人 | 两个共享生命的道人 |
| 通关 | 两个都倒下时，合为一个完整的道人，说了一句"谢谢你" |

**情节作用**：讲"分裂"的主题，呼应你的心魔与选择。

### 第八关 · 雷池（大乘）

| 项 | 内容 |
|---|---|
| 地方 | 一片被雷劈了千年的焦土 |
| 守关者 | **雷部残将** |
| 来历 | 当年剿灭你师门的人，是雷部的兵 |
| 敌人 | 雷兽、天兵 |
| 通关 | 残将死前告诉你真相：**灭门不是仇，是任务** |

**情节作用**：翻转。你一路以为在复仇，其实对方只是执行命令。

### 第九关 · 九霄（渡劫）★

| 项 | 内容 |
|---|---|
| 地方 | 云海之上，什么也没有 |
| 守关者 | **道** |
| 来历 | 所谓九霄之上，只有一道门。门前坐着一个和你一模一样的人 |
| 敌人 | 三阶段：人形（用你的法术）→ 雷云（全场落雷）→ 你自己（用你的流派） |
| 通关 | 你走进去。画面变白。一行字：**"山门已复，你不再需要它了。"** |

**情节作用**：结局不是打败谁，是**放下**。标题《九霄》在这里闭环。

## 路线图

```
乱葬岗(1) ─ 断魂涧(2) ─ 枯骨庙(3)★
                              │ 得残经中卷
                              ↓
万剑冢(4) ─ 镜心湖(5) ─ 悬空栈道(6)★
                              │ 师叔、残经下卷
                              ↓
双生洞(7) ─ 雷池(8) ─ 九霄(9)★
                              │ 真相、结局
```

## 每关的节奏

不是每关都打满时间。按情节分量排：

| 关 | 时长 | 强度 | 原因 |
|---|---|---|---|
| 1 乱葬岗 | 90s | 低 | 教学 + 立情绪 |
| 2 断魂涧 | 100s | 中 | 第一次压力 |
| 3 枯骨庙 | 120s | **高** | 关底 Boss |
| 4 万剑冢 | 120s | 中高 | 剑修专场 |
| 5 镜心湖 | 120s | 中 | 讲情绪，不堆怪 |
| 6 悬空栈道 | 130s | **高** | 关底 + 剧情重 |
| 7 双生洞 | 140s | 高 | 只有两个精英 |
| 8 雷池 | 150s | 极高 | 真相 + 硬仗 |
| 9 九霄 | 180s | 极限 | 三阶段 |

## 关隘之间的过场

**不做过场动画**（成本太高），用**一屏文字 + 一张图**：

```
[背景：乱葬岗的墨色剪影]
  第一关
  乱葬岗
  ──
  "师兄弟都埋在这里。"
  [按 A 继续]
```

8px 字体，中文用 12px。背景用每层的主色，画几个剪影就够。

**为什么不做动画**：一屏文字 30 秒能看完，动画要 3 分钟，
而且 Roguelike 会重复玩，第二次开始玩家会想跳过。

## 情节与玩法的结合点

| 情节节点 | 玩法影响 |
|---|---|
| 3 关得残经中卷 | 解锁魔修路线 |
| 4 关得断剑 | 剑修可锻造，其他流派可卖（换道行） |
| 5 关接受心魔 | 魔修上限提高；拒绝则剑修/法修得到净化词条 |
| 6 关师叔之死 | 得到残经下卷，解锁融合的第二层 |
| 8 关得知真相 | 第九关的 Boss 变成"你自己的选择" |

**每一个剧情节点都改数值或解锁内容**，否则玩家会觉得"故事是多余的"。

## 还没定的

1. **第一遍和后面几遍的过场是否不同**？现在计划：第一遍完整，第二遍起可跳过。
2. **5 关的"接受心魔"是否可逆**？现在设计是不可逆，影响整局。
3. **9 关的结局是否只有一种**？现在只有"走进去"。可能要有"转身离开"的第二种结局。
4. **要不要做支线**？现在全是主线。支线会增加重玩价值，但也会让 25 分钟变长。
