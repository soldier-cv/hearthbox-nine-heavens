# 美术规范

> 定完不要改。改了所有素材要重画。

## 五项写死

| 项 | 值 |
|---|---|
| 逻辑分辨率 | **320 × 180** |
| sprite 网格 | **16 × 16** |
| 描边 | 1px `#14141c` |
| 光源 | 左上 |
| 命名 | `spr_<类别>_<名>_<帧号>` |

**为什么是 320×180**：1080p 上是 6 倍整数放大，4K 上 12 倍，不出毛刺。再大一号（480×270）在电视上会让像素点变小，10-foot 距离看不清。

| 11 | **`#4ade80`** | 木 / 恢复 / 生命 |

| 13 | **`#60a5fa`** | 雷 / 信息 |

| 15 | **`#f472b6`** | 危险 / 伤害 |
| 16 | **`#c084fc`** | 渡劫 / 神秘 |

**六系对应六色**：

```
雷 #60a5fa / #818cf8
火 #f5a524 / #ff6b35
冰 #2dd4bf
木 #4ade80
金 #f5a524（与火共用主色，靠形状区分）
风 #9a9ab0（透明感）
```

金与火共用 `#f5a524` 是有意的：修仙里"金"常表现为金色光芒，和火的主色接近。靠**形状**区分——火是跳动的团，金是棱角。

## 命名规则

```
spr_hero_idle_0.png
spr_hero_walk_0.png
spr_enemy_fox_0.png
spr_fx_thunderball_0.png
spr_ui_card_frame.png
```

前缀固定三类：`spr_`（sprite）、`fx_`（特效）、`ui_`。

## 导出要求

- [ ] 原尺寸导出，不缩放（缩放交给平台）
- [ ] 无抗锯齿边缘
- [ ] 只用色板内颜色
- [ ] 背景透明用真 alpha，不填洋红
- [ ] PNG-8 优先（文件小），需要渐变才用 PNG-24

## 界面文字

用系统等宽字体，8px 与 12px 两档。

```ts
g.font = '8px monospace';    // 数值、提示
g.font = '12px monospace';   // 标题、卡片
```

**中文在 8px 下会糊**，所以：

- 8px 只用数字与英文（`HP 100`、`1/5`）
- 中文一律 12px 起
- 法术名、境界名用 12px
