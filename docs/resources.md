# 资源与成长

> 两层等级是这个游戏的骨架：**关外积累，关内爆发**。

## 两层等级

| | 关外等级 | 关内等级 |
|---|---|---|
| 范围 | 1-30，持久 | 每局从 0 开始 |
| 资源 | 修为 | 道行 |
| 作用 | 属性基础值、解锁功法 | 三选一的临时强化 |
| 重置 | 不重置 | 每局清空 |
| 每局能升几次 | — | 约 12 次 |

**关外给起点，关内给这一局的表现。**

## 关外成长

### 修为从哪来

| 行为 | 修为 |
|---|---|
| 通关第 1 关 | 20 |
| 通关第 2 关 | 30 |
| 通关第 3 关 | 50 |
| 通关第 4 关 | 65 |
| 通关第 5 关 | 80 |
| 通关第 6 关 | 100 |
| 通关第 7 关 | 120 |
| 通关第 8 关 | 145 |
| 通关第 9 关 | 200 |
| 首通某关 | 额外 +50% |
| 重刷已通关的关 | 减半 |

**重刷减半**：鼓励往上打，不是刷第 1 关。

### 修为怎么花

**不是自动升级，是自己分配。** 每升一级给 3 点。

| 属性 | 每点效果 | 上限 |
|---|---|---|
| 气血 | +12 | 无 |
| 灵力 / 剑意 / 魔气上限 | +8 | 无 |
| 移动速度 | +2% | +30% |
| 技能伤害 | +3% | +45% |
| 冷却缩减 | +2% | +30% |
| 暴击率 | +2% | +40% |
| 击杀回血 | +1 | +15 |

**为什么让玩家分配**：全点气血和全点伤害，打起来完全不一样。

### 升级门槛

```
升到 N 级需要：100 × N^1.6（累计）
1→2：100
5→6：约 1310
10→11：约 2980
29→30：约 16000
```

一局约 200 修为，从 1 级到 30 级约 40-50 关，20 小时左右。

**这是长线目标，不是一晚上能打满的。**

## 关内成长

### 道行从哪来

| 来源 | 道行 |
|---|---|
| 杀杂兵 | 3 |
| 杀精怪 | 8 |
| 杀妖将 | 18 |
| 杀 Boss | 60 |
| 过关 | 25 |

### 道行怎么用

满了给三选一：

| 类型 | 出现率 | 例子 |
|---|---|---|
| 强化现有技能 | 40% | 青锋式伤害 +15% |
| 新技能 | 25% | 学会回风斩 |
| 属性 | 25% | 气血上限 +20 |
| 稀有词条 | 10% | 剑意不再因受击掉落 |

**每局约 12 次三选一**，不管关外多少级都一样。

### 升级门槛

```
第 N 次升级需要：20 + N × 15 道行
第 1 次：35
第 5 次：95
第 12 次：200
```

## 六种资源

| 资源 | 谁用 | 从哪来 | 跨局？ |
|---|---|---|---|
| 气血 | 全部 | 初始 100，过关回满 | 否 |
| 灵力 | 道人 | 每秒回 3，击杀回 8 | 否 |
| 魔气 | 魔头 | 每次施法累加 | 否 |
| 剑意 | 剑客 | 命中叠层 | 否 |
| 道行 | 全部 | 击杀 / 过关 | 否 |
| **修为** | 全部 | 通关 | **是** |

## 回复手段

| 方式 | 强度 | 谁有 |
|---|---|---|
| 击杀回血 | +2 | 全部（可被修为加点提升） |
| 过关回满 | 回满 | 全部 |
| 吸血 | 伤害的 15% | 只有魔头（需打通分支） |
| 回春类技能 | 每秒 4 | 道人分支 |

**为什么击杀回血只有 2 点**：一局约 300 个敌人，全吃能回 600 血。
但普通怪伤害 8-20，被围三下就没了。2 点是喘息，不是续航。

**回复必须少于伤害**，否则玩家会站着不动硬扛。

## 功法解锁（关外）

| 关外等级 | 解锁 |
|---|---|
| 1 | 3 个初始技能 |
| 5 | 每个技能的第 1 条分支 |
| 10 | 每个技能的第 2 条分支 |
| 15 | 第一条融合 |
| 20 | 第二条融合 |
| 25 | 跨部融合（仅特定角色） |
| 30 | 终极形态 |

**为什么功法也要关卡外解锁**：否则等级只影响数值，不影响玩法。

## 仙缘（三个角色共享）

这是唯一跨角色共享的东西。

| 仙缘 | 条件 | 效果 |
|---|---|---|
| 见山门 | 任意角色通关第 3 关 | 解锁第 4 关的隐藏商人 |
| 剑冢留名 | 剑客通关第 6 关 | 三角色可得"断剑" |
| 雷部有缺 | 道人通关第 6 关 | 三角色可见雷池真相 |
| 魔道初成 | 魔头通关第 6 关 | 三角色可在第 5 关接受心魔 |
| 九霄之巅 | 任意角色通关第 9 关 | 解锁隐藏角色 |

**只解锁内容，不给数值。** 不然通关一个角色会让另外两个变简单。

## 一局的资源流向

```
进关卡      带上关外属性
  ↓ 第 1 关
打怪        道行 +3/杀，气血 -8/被击
  ↓ 道行满
三选一      强化 / 新技能 / 属性 / 稀有词条
  ↓ 第 3 关
关底        道行 +60，可能弹分支
  ↓ …
  ↓ 第 9 关
通关        修为 +200，回山
```

## 三个角色的资源独立

| | 剑客 | 道人 | 魔头 |
|---|---|---|---|
| 关外等级 | 独立 | 独立 | 独立 |
| 修为 | 独立 | 独立 | 独立 |
| 功法解锁 | 独立 | 独立 | 独立 |
| 已通关卡 | 独立 | 独立 | 独立 |
| 仙缘 | **共享** | **共享** | **共享** |

**练三个角色是三倍时间。** 这是设计选择——三个故事，三份投入。

## 还没定的

1. **修为点能不能洗**？现在不能。洗点削弱选择的重量，但不洗会让玩家后悔。
2. **等级封顶 30 之后**？现在没有后续。可能要"转世"或其他长线目标。
3. **重刷关卡是否给功法进度**？现在只给修为（且减半），不给功法。
4. **推荐等级**：第 N 关推荐关外多少级？现在没定，需要实测。
