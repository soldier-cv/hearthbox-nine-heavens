# 资源与成长

> 两层等级是这个游戏的骨架：**关外积累，关内爆发**。
>
> 数值见 `systems.md`。这份只讲结构。

## 两层等级

| | 关外等级 | 关内等级 |
|---|---|---|
| 范围 | 1-30，持久 | 每局从 0 开始 |
| 资源 | 修为 | 道行 |
| 作用 | 属性基础值、解锁功法 | 三选一的临时强化 |
| 重置 | 不重置 | 每局清空 |
| 每局能升几次 | — | 12 |

**关外给起点，关内给这一局的表现。**

## 关外成长

### 修为从哪来

| 行为 | 修为 |
|---|---|
| 通关第 N 关 | 1,200 + 600 × N |
| 首通某关 | 额外 +50% |
| 重刷已通关的关 | 减半 |
| 一局九关全通 | 37,800 |

**重刷减半**：鼓励往上打，不是刷第 1 关。

**首通 +50% 是有意的**：第一次打到新关卡永远是最赚的，
这样"往上走"永远比"刷旧的"划算。

### 修为怎么花

**关外不再手动加点。** 修为只负责升级，属性每级怎么涨**由开局掷的天资决定**，
自动结算，玩家不用点任何东西。

| 天资 | 涨什么 | 30 级上限 |
|---|---|---|
| 体魄 | 气血、击杀回血 | 气血带底数，差距压到约 1.45 倍 |
| 灵机 | 灵力 / 魔气上限、冷却缩减 | 冷却 +30% |
| 身法 | 移动速度 | +30% |
| 杀伐 | 伤害、暴击率 | 伤害 +45%，暴击 40%（含基础 8%） |

**为什么不做手动加点**：关外这一层玩家真正做的决定只有一次——掷骰。
再给 87 个点去分配，只是在让他把同一件事再说一遍。
想决定"这一局怎么打"，那是关内三选一的事，两层分工不重叠。

**天资怎么掷、每级涨多少**见 `systems.md` 的「关外成长」。

### 升级门槛

```
升到 N 级需要：1,400 × (N-1)^1.2（本级）
```

| 等级 | 本级 | 累计 | 折合局数 |
|---|---|---|---|
| 5 | 7,400 | 17,200 | 0.5 |
| 10 | 19,600 | 90,000 | 2.4 |
| 15 | 33,200 | 228,300 | 6.0 |
| 20 | 47,900 | 438,100 | 11.6 |
| 25 | 63,400 | 724,000 | 19.2 |
| 30 | 79,600 | 1,089,400 | 28.8 |

**一个角色练满约 29 次九关（约 10 小时）。三个角色约 30 小时。**

旧版的 `100 × N^1.6` 算下来是 **25 万修为 / 315 局 / 131 小时**，
和 `pitch.md` 写的"20-40 小时"差了五倍。已改。

## 关内成长

### 道行从哪来

| 来源 | 道行 |
|---|---|
| 杀杂兵 | 1,100 |
| 杀精怪 | 4,400 |
| 杀妖将 | 22,000 |
| 杀 Boss | 110,000 |
| 过关 | 45,000 |

### 道行怎么用

满了给三选一：

| 类型 | 出现率 | 例子 |
|---|---|---|
| 强化现有技能 | 40% | 青锋式伤害 +18% |
| 新技能 | 25% | 学会回风斩 |
| 属性 | 25% | 气血上限 +20% |
| 稀有词条 | 10% | 剑意不再因受击掉落 |

**每局 12 次三选一**，不管关外多少级都一样。

三选一的分配见 `systems.md`：前 4 关只给 4 次，后两关给 5 次。

### 升级门槛

```
第 N 次：100,000 + 9,000 × (N-1)
```

门槛涨得很慢（每次 +9%），因为一局只有 12 次。
涨得快会让"下一次升级"变得遥远，而玩家一局只打 20 分钟。

## 六种资源

| 资源 | 谁用 | 从哪来 | 跨局？ |
|---|---|---|---|
| 气血 | 全部 | 初始 20,000，过关回满 | 否 |
| 灵力 | 道人 | 上限 100，进关带 60，每秒回 8 | 否 |
| 魔气 | 魔头 | 每次施法累加，不打就衰减 | 否 |
| 剑意 | 剑客 | 命中叠层，受击掉一半 | 否 |
| 道行 | 全部 | 击杀 / 过关 | 否 |
| **修为** | 全部 | 通关 | **是** |

## 回复手段

| 方式 | 强度 | 谁有 |
|---|---|---|
| 击杀回血 | 气血上限的 0.3% | 全部（可被修为加点提升） |
| 过关回满 | 回满 | 全部 |
| 吸血 | 伤害的 15% | 只有魔头（需打通分支） |
| 回春类技能 | 每秒 0.5% 最大气血 | 道人分支 |

**为什么击杀回血只有 0.3%**：一局约 400 个敌人，全吃能回 3.6 万。
但一局承受的伤害在 8~15 万之间。**回复只占三分之一。**

**回复必须少于伤害**，否则玩家会站着不动硬扛。

## 功法解锁（关外）

| 关外等级 | 解锁 |
|---|---|
| 1 | 3 个初始技能 |
| 5 | 每个技能的第 1 条分支 |
| 10 | 每个技能的第 2 条分支 |
| 15 | 第一条融合 |
| 20 | 第二条融合 |
| 25 | 第三条融合 |
| 30 | 终极形态 |

**为什么功法也要关卡外解锁**：否则等级只影响数值，不影响玩法。

## 仙缘（三个角色共享）

这是唯一跨角色共享的东西。

| 仙缘 | 条件 | 效果 |
|---|---|---|
| 见山门 | 任意角色通关第 1 关 | 第二角色可选 |
| 剑冢留名 | 剑客通关第 4 关 | 剑客分支：血刃 |
| 雷部有缺 | 道人通关第 4 关 | 道人分支：九幽雷 |
| 魔道初成 | 魔头通关第 4 关 | 魔头分支：魔域 |
| 九霄之巅 | 任意角色通关 | 隐藏角色 |

**只解锁内容，不给数值。** 不然通关一个角色会让另外两个变简单。

## 一局的资源流向

```
进关卡      带上关外属性（气血 20,000 起）
  ↓ 第 1 关
打怪        道行 +1,100/杀，气血 -1,300/被杂兵击
  ↓ 道行满（第 1 关末，1 次）
三选一      强化 / 新技能 / 属性 / 稀有词条
  ↓ 第 3 关
关底        道行 +110,000，混到第 4 次升级
  ↓ …
  ↓ 第 9 关
通关        修为 +6,600，回山
```

## 三个角色的资源独立

| | 剑客 | 道人 | 魔头 |
|---|---|---|---|
| 关外等级 | 独立 | 独立 | 独立 |
| 修为 | 独立 | 独立 | 独立 |
| 功法解锁 | 独立 | 独立 | 独立 |
| 已通关卡 | 独立 | 独立 | 独立 |
| **关卡顺序** | **独立** | **独立** | **独立** |
| 仙缘 | **共享** | **共享** | **共享** |

**练三个角色是三倍时间。** 这是设计选择——三个故事，三份投入。

## 存档结构（开发前必须定）

这是**当前文档最大的空白**。游戏需要三个独立的存档槽，每个包含：

```
save/
├── meta          { 已解锁角色, 仙缘, 全局设置 }
└── char-<id>     { 关外等级, 修为, 修为点分配, 已解锁功法,
                    已通关卡, 当前第几关, 血债簿进度（魔头专用）}
```

**必须现在就定，因为平台不给"多存档槽"**——`ctx.storage` 是一个
键值对，整个游戏共用一个。要么把三份存档塞进一个 JSON 里，
要么按角色分键（`char-swordsman` / `char-daoist` / `char-demon`）。

**推荐分键。** 理由：单份存档坏掉不会带走另外两个角色的进度。

**存档版本号必须从第一版就有**：
`{ v: 1, ... }`。发布后发现要改结构，没有版本号就只能清档。

## 还没定的

1. **修为点能不能洗**？现在不能。洗点削弱选择的重量，但不洗会让玩家后悔。
   折中方案：通关一次给一次免费洗点。
2. **等级封顶 30 之后**？现在没有后续。可能要"转世"或其他长线目标。
3. **23-30 级给什么**？现在只有数值，第 9 关推荐 22 级，23 级之后没有新内容。
4. **重刷关卡是否给功法进度**？现在只给修为（且减半），不给功法。
5. **存档方案**：分键还是单键 JSON？上面推荐分键，需要定。
