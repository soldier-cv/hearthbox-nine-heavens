# 关卡设计

> 九关对应九个境界，也对应九处地形。
>
> **三条线走的顺序不同、目标不同、机制也不同。**
> 形状分配的求解过程见 `routes.md`，敌人见 `enemies.md`。

## 只有一个规则：形状

关卡不是一关一关手搓的，是 **地形 × 形状 × 目标**。

```
8 个形状 × 3 个目标 ≈ 11 套代码，27 个配置
```

| 形状 | 玩什么 | 结束条件 |
|---|---|---|
| `HOLD` | 波次从四面涌向一个点 | 撑满 / 目标存活 |
| `RUN` | 从 A 推到 B | 到达出口 |
| `HUNT` | 目标会跑 | 打死 / 追上 / 逃脱 |
| `SWARM` | 被围要打出口 | 杀够数 / 突围 |
| `TRAP` | 场地规则周期改变 | 撑满 / 达成目标 |
| `DUEL` | 一个敌人，无杂兵 | 打死 / 熬过阶段 |
| `DUO` | 两个战场同时进行 | 两边都达成 |
| `SET` | 一次性脚本关 | 脚本走完 |

**判据**：去掉地形贴图、只留机制，你还分得清是哪一关吗？
分不清就是重复。

## 八个形状怎么写（代码怎么想）

这一节写给实现，不是写给玩家。

### `HOLD` · 阵地

```
状态：守卫物（可选）+ 波次表 + 计时
每帧：波次计时到 -> 从场边生成 -> 敌人朝"守卫物"走
判负：守卫物血归零 / 玩家死
判胜：计时到
```

**关键**：敌人必须有"要去的地方"，不能只朝玩家走。
否则守着的东西没有意义，玩家把它拖走就行了。

### `RUN` · 行进

```
状态：分段数组 [ {长度, 地形, 敌人表} ] + 当前段号 + 推进距离
每帧：玩家前进 -> 推进距离 += dn
      推进距离 > 段长 -> 切下一段（换背景、换刷怪表）
判胜：推进距离 >= 总长
```

**关键**：不是"滚屏"。是**切段**——320×180 的画面上滚屏只会糊。
一段就是一块固定场地，走到边上"翻页"。8 段能做出 8 屏长的路。

### `HUNT` · 猎杀

```
状态：目标（逃跑 AI）+ 逃脱计时
逃跑 AI：每帧远离玩家，遇墙沿墙；每隔 N 秒换方向
判胜：目标死 / 玩家追上
判负：逃脱计时归零（或按设计不判负，只扣奖励）
```

**关键**：逃得动才行。目标速度必须略低于玩家速度（70~85%），
否则玩家会觉得自己在追一个不会累的东西，很烦。

### `SWARM` · 围杀

```
状态：环形生成器 + 杀数/包围圈半径
每帧：生成 -> 敌人在环上等距分布 -> 同时向内收
判胜：杀够数 / 打出缺口（连续 3 秒圈内无敌人）
```

**关键**：收得慢。收得快就是"你没得选"。圈要从 R=180 收到 R=40，用 15 秒。

### `TRAP` · 机关

```
状态：机关数组 [ {类型, 位置, 周期, 相位, 预警时长, 生效时长} ]
每帧：机关按相位推进，只在预警/生效两态做事
判胜：按目标（撑满 / 清空机关）
```

**关键**：机关和敌人是**两套独立系统**，不共用计时。
否则玩家会看出"机关是为刷怪服务的"。

### `DUEL` · 对决

```
状态：Boss 阶段机 + 无波次
每帧：按阶段跑招式表
判胜：Boss 死 / 达成目标（有的对决不要求杀死）
```

**关键**：**绝对不刷杂兵。** 一旦有杂兵，玩家的注意力就被分走了，
对决的情绪就没了。

### `DUO` · 双线

```
状态：两个目标 + 共享或独立血条
每帧：两个目标各自跑 AI
判胜：两边都达成
```

**关键**：共享血条时，**回血必须能被低 DPS 打法压住**。
旧版（5 秒回 5%）算出来道人的 DPS 是负的，永远打不死。已改。

### `SET` · 演出

```
状态：事件表 [ {时间/条件, 做什么} ]
每帧：推进事件表，不刷怪（或按脚本刷）
判胜：脚本走完
```

**关键**：场景里的东西可以违反常规规则（敌人在打别人、NPC 不可攻击）。
**这是唯一允许"机制不讲道理"的形状**，因为它服务叙事。

### 第 1 关 · 乱葬岗（炼气 · `HOLD`）

| 项 | 内容 |
|---|---|
| 场景 | 荒坟、残碑、歪斜的枯树，中间一块木牌 |
| 敌人 | 腐尸（不动，会爬向木牌）、噬骨鸦（俯冲） |
| 守卫物 | 木牌，血量 = 玩家气血 × 2 |
| 时长 | 90 秒 |
| 目的 | 教会三件事：移动、出手、**守住一个东西** |

**为什么第一关是守而不是打**：守住一个点比追着打更容易理解。
玩家站在木牌旁边，敌人自己过来——**他不需要先学会走位，就能打到东西。**

**腐尸的机制**：它不动，但它会"爬"——每 3 秒朝木牌挪 8 像素。
玩家必须在它够到木牌之前清掉。**这是第一次让玩家理解"敌人有目的地"。**

### 第 4 关 · 万剑冢（元婴 · `DUEL`）

| 项 | 内容 |
|---|---|
| 场景 | 满谷断剑，插在地上 |
| 敌人 | 剑冢守灵，一个 |
| 机制 | **无杂兵**。守灵有 3 个阶段，每阶段换一套剑招 |
| 时长 | 120 秒 |

**阶段**：
1. **守**：它不主动打，只挡。玩家要打穿它的格挡
2. **攻**：剑阵横扫，1.5 秒预警
3. **认**：它认出玩家是归一门的人，停手，把断剑递过来

**第三阶段是设计的关键**：这场对决的结束不是"打死它"，
是"它认你"。玩家会在这里第一次遇到"赢了但不是杀掉"的敌人。
（目标仍写"杀"，因为实现上血条要清零。**但表现上是它自己散的。**）

### 第 5 关 · 镜心湖（化神 · `SET`）

| 项 | 内容 |
|---|---|
| 场景 | 湖面如镜，倒映的不是你 |
| 敌人 | 妄念（复制你的轨迹）、心魔（复制你的法术） |
| 机制 | **画面去饱和**。视野边缘收窄到 70%，看不清角落 |
| 时长 | 120 秒 |
| 选择 | 结束时：接受心魔 / 拒绝心魔 |

**接受** = 剑意不再因受击掉落，但进关卡时气血 -15%
**拒绝** = 得到"净化"词条（受击时剑意只掉 1/4），但没有剑意保护

**两个选项必须都有人选。** 如果一个明显更优，这条设计就是假的。

### 第 6 关 · 悬空栈道（炼虚★ · `RUN`）

| 项 | 内容 |
|---|---|
| 场景 | 贴在绝壁上的木板路，多处已经断了 |
| 敌人 | 山魈（扑击）、坠石（定点落下） |
| 目标 | 40 秒内跑到栈道尽头 |
| 时长 | 130 秒 |

**这是全篇最重的一场戏。** 而且它的机制就是这场戏：

- 你要在 40 秒内跑到他面前
- 路上有山魈和塌陷挡着
- **你打他一次，他就早跳 0.5 秒**

玩家第一次打他的时候，会看到倒计时突然缩短。
那一刻他会明白：**这个人不是敌人，他在等一个结果。**

**如果超时**：他自己跳下去，你捡到他留下的半卷残经，但拿不到完整奖励。
**不判负。** 因为他本来就要跳。

### 第 7 关 · 双生洞（合体 · `DUO`）

| 项 | 内容 |
|---|---|
| 场景 | 一个洞口，两条路，通向同一个大厅 |
| 敌人 | 双子道人（共享生命，独立回复） |
| 机制 | **只有两个精英**，不刷杂兵 |
| 时长 | 140 秒 |

**共享生命 + 独立回复**：
- 两个共享一条血条
- 但每个 2 秒不受伤就回 2%
- 玩家要同时压制两边

**旧版是 5 秒回 5%**，算下来道人的 DPS 是负的（永远打不死）。已改。

### 第 8 关 · 雷池（大乘 · `HOLD`）

| 项 | 内容 |
|---|---|
| 场景 | 被雷劈了千年的焦土，一道门在最高处 |
| 敌人 | 天兵（成群）、雷兽（引雷）、雷部残将 |
| 守卫物 | 门（玩家要守住它不被撞开） |
| 时长 | 150 秒 |

**为什么是守**：剑客的一路都在"守"。
最后这一关，他守的不再是别人的东西，是**他自己要过去的那道门**。

### 第 9 关 · 九霄（渡劫★ · `DUEL`）

| 项 | 内容 |
|---|---|
| 场景 | 云海之上，什么也没有。一道门，门前坐着一个和你一样的人 |
| 敌人 | **道**（三阶段） |
| 机制 | 每阶段换一套机制 |

| 阶段 | 形态 | 用什么打你 |
|---|---|---|
| 一 | 人形 | 你会过的所有法术 |
| 二 | 雷云 | 全场落雷 + 召唤天兵 |
| 三 | **你自己** | 你的流派、你的习惯 |

**设计意图**：最终的敌人是你自己。你的流派越强，它越强。

### 第 2 关 · 枯骨庙（筑基 · `DUEL` 达）

| 项 | 内容 |
|---|---|
| 场景 | 破庙，供着一尊骨佛，香炉还在冒烟 |
| 敌人 | 骨佛（不主动攻击，只在被激怒时反击） |
| 目标 | **撑 20 秒，取到佛像肚子里的经，然后走** |
| 时长 | 120 秒 |

**怎么玩**：

- 佛像不还手，但它的香炉每 2 秒掉你血
- 你要走到佛像前（会被推开），取经（要 3 秒读条）
- 骨僧会来拦你，但**你不必杀它们**，绕过去就行
- 取到经，门就开了

**为什么是 `DUEL`**：这是唯一一个"有一个不还手的大 Boss"的关。
骨佛是他这条线里唯一"看起来像敌人但打不还手"的东西。
**玩家会犹豫要不要打它——这个犹豫就是设计。**

**如果玩家硬要打死骨佛**：可以，但要花掉 90 秒，而且拿不到"不杀"的额外道行。
**不惩罚，只是不给奖励。**

### 第 3 关 · 乱葬岗（金丹★ · `SET` 守）—— 不杀关

| 项 | 内容 |
|---|---|
| 场景 | 一排新坟，一块木牌，写着"归一门" |
| 敌人 | 尸傀（穿着归一门外门服） |
| 机制 | **你的攻击对尸体无效** |
| 时长 | 120 秒 |
| 目标 | 在坟前坐满一夜（撑住） |

**怎么玩**：

1. 尸体从坟里站起来，慢慢围过来
2. 你打不动它们——攻击穿过，没有伤害数字
3. 你只能走位、用轻身诀、等天亮
4. 尸体会在碰到你之后**停一下**，然后走开——它们不是在攻击你，是路过
5. 撑到 120 秒，天亮，它们躺回去

**玩家会经历三个阶段**：

- 前 30 秒：反复尝试攻击，怀疑是不是 bug
- 中 60 秒：放弃攻击，开始躲
- 后 30 秒：发现它们不追你，开始**看**它们

**这一关的目的是让玩家停下来。** 一个 Roguelike 里放一个不能打的关，
是风险很高的设计。但道人的整个人设就是这个——
**他不是来杀的，游戏也不能逼他杀。**

**技术要点**：

- 攻击不做伤害判定，但要**有击中的反馈**（特效穿过、没有数字）
- 尸体必须有"不是敌人"的视觉线索（半透明、无血条、移动很慢）
- 木牌上的字随时间一段段显示，撑满 120 秒刚好读完

**这最后一句话很重要**：玩家第 30 秒就猜到了"打不动"，
但剩下的 90 秒要有东西看。**木牌上的字就是那段东西。**

### 第 5 关 · 万剑冢（化神 · `SWARM` 达）

| 项 | 内容 |
|---|---|
| 场景 | 满谷断剑，插在地上 |
| 敌人 | 无主飞剑（直线冲刺，不看玩家位置） |
| 目标 | **穿过剑谷，到对面的出口** |
| 时长 | 120 秒 |

**为什么是 `SWARM` 而不是 `RUN`**：这一关不是"往下走"，
是"剑从四面八方向你压过来，你必须打出一个缺口往前走"。

**玩家可以完全不还手**——只靠走位穿过。但剑越来越密，
不还手会很难。**这是他的"不杀"里最难的一次。**

### 第 7 关 · 悬空栈道（合体 · `HUNT` 达）

| 项 | 内容 |
|---|---|
| 场景 | 栈道，尽头是断口 |
| 目标 | 那个人站在断口边 |
| 机制 | **追上=成功，打他=失败** |
| 时长 | 120 秒 |

**怎么玩**：

- 他在前面走，速度是玩家的 85%
- 他要走到断口然后跳下去
- **你打中他 → 他停下 → 你立刻失败**（关卡结束，给"你没追上"的结算）
- 你不能用任何伤害技能，只能用移动和位移技

**为什么"打他就算失败"**：这一关的题目是"你能不能只是路过"。
玩家手上只有一个键能按，而这个键在这里会犯下错误。

**这是全游戏唯一一关会惩罚攻击。**

### 第 8 关 · 雷池（大乘 · `TRAP` 守）

| 项 | 内容 |
|---|---|
| 场景 | 焦土，被雷劈了千年，一直在落雷 |
| 敌人 | 天兵（成群，但不是主角） |
| 机制 | **没有 Boss**：落雷越来越密 |
| 时长 | 150 秒 |

**设计意图**：这是三条线里唯一一个"没有守关者"的关。
雷池不需要有人守，它自己就会杀死你。

**难度曲线**：落雷间隔从 2.5 秒压到 0.8 秒。
玩家会死在这里，而且会觉得是自己的问题——这正是设计想要的。

### 第 1 关 · 乱葬岗（炼气 · `SWARM` 杀 30）

| 项 | 内容 |
|---|---|
| 场景 | 十七个新坟，坟是空的 |
| 敌人 | 尸傀、同门（穿归一门外门服） |
| 机制 | **尸体倒下一次会再站起来一次** |
| 时长 | 110 秒 |
| 目标 | 杀 30 只 |

**怎么玩**：

- 每只尸体要打两遍——第一次倒下是"还没死透"
- 第二次才真的碎
- 穿外门服的那种（同门）会跪下来一次，然后才站起来继续走

**为什么这样设计**：玩家会砍到自己认识的人。
第一次倒下时他会以为结束了，站起来时他必须再砍一次。
**这就是"血债"的第一次预演。**

**难度注意**：这是三条线里最难的第 1 关。
它排在剑客通关第 3 关之后解锁，所以玩家已经有 3 关经验。

### 第 3 关 · 枯骨庙（金丹★ · `TRAP` 杀）

| 项 | 内容 |
|---|---|
| 场景 | 破庙，佛像，四个香炉 |
| 敌人 | 骨僧、骨佛 |
| 机制 | **打碎香炉会炸全场** |
| 时长 | 120 秒 |

**机制是一个交易**：

- 香炉每 2 秒全场掉血（气血 ÷ 50）
- 打碎一个香炉 → 它炸 → 立刻受到 气血 ÷ 8 的伤害
- 但打碎后掉血停了

**算一下**：四个香炉全打碎 = 4 × （气血÷8）= **半管血**。
不打，120 秒要掉 **1.2 管血**。
**所以必须打碎，但要挑时机——血少的时候先打，血多的时候等一等。**

**这是他这个角色第一次"用血换时间"。**

### 第 4 关 · 镜心湖（元婴 · `DUEL` 杀）

| 项 | 内容 |
|---|---|
| 场景 | 湖面如镜，倒映的是三十年前的他 |
| 敌人 | 血衣（旧我） |
| 机制 | **旧他没有魔气消耗** |
| 时长 | 120 秒 |

**怎么玩**：

- 旧我用同样的技能，但**冷却更短、伤害不衰减**
- 他的血量是玩家的 4 倍（Boss 倍率）
- 玩家如果一直"稳着打"，会被慢慢磨死
- **唯一赢的办法是入魔**——用 +100% 伤害换 30% 气血

**这是全游戏最重要的一关**，因为它把"魔头的代价"变成了**解法**。
前面每一关代价都是负担，这一关它第一次是优势。

### 第 5 关 · 悬空栈道（炼虚★ · `SET` 杀）

| 项 | 内容 |
|---|---|
| 场景 | 栈道，尽头坐着一个人 |
| 敌人 | 守栈人（必须杀） |
| 机制 | **不能绕，没有对话选项** |
| 时长 | 130 秒 |

**和剑客的同一场戏，完全相反**：

| | 剑客 | 魔头 |
|---|---|---|
| 他到的时候 | 老头还在 | 老头还在 |
| 玩家要做 | 40 秒内跑到他面前 | 杀了他 |
| 老头说的话 | 「上去吧。别回头。」 | 「那你也得死。」 |
| 结果 | 老头自己跳下去 | 老头死，下卷掉出来 |

**老头的袖子里有半块木牌**——那是剑客的通关信物。
魔头这边不会解释它是什么，玩家要玩过剑客线才认得出。

**这就是三条线的交叉方式**：不是剧情同步，是同一样东西在三个人手上。

### 第 8 关 · 雷池（大乘 · `SWARM` 杀 80）

| 项 | 内容 |
|---|---|
| 场景 | 焦土，天兵列阵，门在最后面 |
| 敌人 | 天兵（海量）、雷兽、残将 |
| 机制 | **攻城**：杀够 80 只，门才开 |
| 时长 | 160 秒 |

**和剑客的同一场戏**：

- 剑客是守，守住门不被撞开
- 魔头是攻，杀到门自己开

**这是全游戏唯一一关"杀够数"直接写在胜利条件里。**
因为这是他最后一个人。杀完他，簿子上就没名字了（除了第七行）。

### 第 9 关 · 九霄（渡劫★ · `DUEL` 杀不成）

| 项 | 内容 |
|---|---|
| 场景 | 门前没有人，只有一本摊开的簿子 |
| 敌人 | 没有 |
| 机制 | **第三阶段他杀不了** |
| 时长 | — |

**三阶段**：
1. 打道（人形）——能打
2. 打道（雷云）——能打
3. **道变成他自己的样子，站着不动，血条不出现**

**第三阶段没有血条。** 玩家会对着一个打不动的东西砍很久。
然后道说话：「这一行，你自己填。」

**这是全游戏唯一一关"打赢了但没有结算画面"。**
只有一个画面变白，一行字。

## 关与关之间的节奏

```
剑客   1守 2走 3机关 4决 5演 6走 7双 8守 9决
道人   1走 2决 3演 4走 5围 6演 7追 8机关 9演
魔头   1围 2追 3机关 4决 5演 6双 7追 8围 9决
```

**三条线的节奏形状完全不同**：

- **剑客**：两头是守，中间是一段路。他的线是"回到原点"。
- **道人**：三个 `SET` 分散在第 3、6、9 关——**每隔三关停一次**。
  他的线是有呼吸的。
- **魔头**：**从围杀开始，到对决结束，中间全是追和杀。**
  他的线是"越收越紧"。

**相邻两关形状不能相同**（硬规则）。三条线都满足。

## 每关的固定账

**每一关的敌人是定量的，不是无限的。** 一关打多久、出多少只、能升几次，进关前就定死了。

| 关 | 时长 | 刷怪节奏 | 本关怪物数 | 关内累计升级 |
|---|---|---|---|---|
| 1 | 90 s | 每 3.0 s 一只 | 30 | 1 |
| 2 | 100 s | 每 2.4 s 一只 | 42 | 3 |
| 3 | 120 s | 每 2.2 s 一只 + 四个机关 | 55 | 5 |
| 4 | 120 s | 每 2.0 s 一只，环形 | 60 | 6 |
| 5 | 120 s | 无杂兵，1 个镜像 | 1 | 7 |
| 6 | 130 s | 每 1.9 s 一只 | 68 | 9 |
| 7 | 140 s | 2 个精英，共享血条 | 2 | 10 |
| 8 | 150 s | 每 1.7 s 一只，成群 | 88 | 12 |
| 9 | 180 s | 1 个 Boss，三阶段 | 1 | 12（已满） |

**怪物数 = 时长 ÷ 间隔，不再单独维护一份数字。**
表里的数只用来对账：改节奏就必须重跑 `node tools/check-picks.mjs`。

**为什么必须定量**：定量的怪 = 定量的道行 = 这一局能升几次是算得出来的。
如果怪无限刷，"没打过"就永远可以靠多打几只补回来，关卡就没有压力了。

**漏掉的怪就是少的道行。** 这不是惩罚，是让"这一关打得好不好"真的影响这一局的强度。

## 关内能强到什么程度

**一局固定 12 次三选一，不吃关外等级。** 关外再高，进关也是 12 次。

| 一次三选一 | 给多少 |
|---|---|
| 强化现有技能 | 该技能 +18%（最高 5 级，共 +72%） |
| 学新技能 | 多一个可用槽（最多 3 个） |
| 属性 | 气血 +25% / 伤害 +15% / 冷却 +10% 等 |
| 稀有词条 | 一条改变规则的效果 |
| 融合 | 两个技能换一个形态，融合技每级 +30% |

**技能升到 5 级必出分支二选一，这是质变点。**
5 级前的强化是"数字变大"，5 级的分支是"打法变了"——
一局 12 次里，玩家至少要撞到一次这种质变，否则这一局就是纯数值。

**前提是关外买过这条分支功法**（见 `skills.md` 功法谱）。
没买，技能就停在 5 级，三选一不会再给它卡——这不是 bug，是关外该做的功课。

**关内满配大约是一击 ×3.5**（12 次三选一 × 26% + 资源满层 + 词条）。
所以敌人血量按"进这一关时的玩家"算，而不是按满配算——**打满配是爽，不是必需。**
