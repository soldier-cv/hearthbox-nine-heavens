# 关卡设计

## 结构

九层，对应九个境界。**每三层一个大境界**，第三、六、九层是「关底」。

```
炼气(1) ─ 筑基(2) ─ 金丹(3)★
  └ 大境界突破：三选一稀有词条
化神(4) ─ 炼虚(5) ─ 合体(6)★
  └ 大境界突破
大乘(7) ─ 渡劫(8) ─ 九霄(9)★
```

**实际跑图从 9 层里抽 6 层**，顺序保持，可以跳一层。这样每局 20-25 分钟，不是每次都一模一样。

## 每一层怎么设计

一层 = 一个场景 + 一个专属机制 + 一种敌人配置。

**不要每层只是换背景图。** 层与层之间必须换玩法。

### 第 1 层 · 炼气 · 山门外野林

| 项 | 内容 |
|---|---|
| 敌人 | 木桩妖（不动，血厚）、野狐（直线冲） |
| 机制 | 无。纯教学层 |
| 目的 | 教走位、出手、捡碎片 |
| 时长 | 90 秒 |

**设计意图**：第一层必须能赢。让人体验"进化了一次"的感觉再往下走。

### 第 2 层 · 筑基 · 灵脉洞窟

| 项 | 内容 |
|---|---|
| 敌人 | 石傀（慢，撞墙反弹）、蝠群（多，血少） |
| 机制 | **地形收窄**。两侧有岩壁，活动范围只有中间 60% |
| 目的 | 逼迫近身，让远程法术不再安全 |
| 时长 | 100 秒 |

**设计意图**：第一层学会"站远点打"的人，这层会难受。这是有意的——逼你考虑近身手段。

### 第 3 层 · 金丹 · 废弃丹房 ★

| 项 | 内容 |
|---|---|
| 敌人 | 丹毒（地面持续伤害）、守炉童子（远程） |
| 机制 | **毒雾**。地面随机区域变绿，站上去掉血 |
| 目的 | 考验持续伤害应对，逼玩家移动 |
| 时长 | 120 秒 |

**关底奖励**：大境界突破，三选一稀有词条（如"雷伤 +30%"、"闪避无冷却"）。

### 第 4 层 · 元婴 · 万剑冢

| 项 | 内容 |
|---|---|
| 敌人 | 剑灵（高速直线）、断剑（静止，碰到掉血） |
| 机制 | **剑阵扫过**。每 8 秒一排飞剑横扫，有 1.5 秒预警 |
| 目的 | 考验闪避节奏，不能站桩 |
| 时长 | 120 秒 |

**设计意图**：从这层开始，"站在安全位置输出"不成立了。必须动。

### 第 5 层 · 化神 · 心魔幻境

| 项 | 内容 |
|---|---|
| 敌人 | 你的影子（复制你的法术，伤害减半） |
| 机制 | **画面变灰**，视野边缘收窄（只能看清中心 70%） |
| 目的 | 心理压力，同时考验"打自己" |
| 时长 | 120 秒 |

**设计意图**：这一层难度不是靠数值，是靠**感知**。看不清会让玩家紧张。

### 第 6 层 · 炼虚 · 虚空裂隙 ★

| 项 | 内容 |
|---|---|
| 敌人 | 虚空爬行者（穿墙）、裂隙守卫（分裂） |
| 机制 | **地面时有时无**。裂缝区域踩上去会掉血，且位置每 5 秒变一次 |
| 目的 | 考验位移与预判 |
| 时长 | 130 秒 |

**关底奖励**：第二次大境界突破。

### 第 7 层 · 合体 · 双生道场

| 项 | 内容 |
|---|---|
| 敌人 | 双子（共享生命条，必须同时压制，否则另一个回血） |
| 机制 | 两个精英，血条共享但回复独立 |
| 目的 | 考验输出分配，不能只打一个 |
| 时长 | 140 秒 |

**设计意图**：这一层是"输出压力"测试。如果你的流派爆发不够，这层会超时。

### 第 8 层 · 大乘 · 天雷台

| 项 | 内容 |
|---|---|
| 敌人 | 雷兽（会放雷）、天兵（成群） |
| 机制 | **落雷**。随机位置有预警圈，1 秒后落雷，伤害高 |
| 目的 | 考验资源管理（血、闪避） |
| 时长 | 150 秒 |

**设计意图**：玩家自己的流派如果是雷系，这层会有"主场感"——同样的机制，但你熟。

### 第 9 层 · 渡劫 · 九霄之巅 ★

| 项 | 内容 |
|---|---|
| 敌人 | 天劫本体（三阶段） |
| 阶段一 | 人形，用你见过的所有法术 |
| 阶段二 | 化身雷云，全场落雷 + 召唤小怪 |
| 阶段三 | 幻化成你自己的形态，同时使用你的流派 |
| 机制 | 所有前面出现过的机制都叠一遍 |
| 时长 | 180 秒 |

**设计意图**：最终 Boss 是"你的镜像 + 所有机制"。玩家的流派越强，它越强。这是最公平也最难受的设计。

## 敌人设计原则

每层 2-3 种敌人，必须满足：

| 类型 | 作用 | 例子 |
|---|---|---|
| **靶子** | 血厚不动，给玩家输出 | 木桩妖 |
| **冲刺者** | 逼你闪避 | 野狐、剑灵 |
| **远程** | 逼你走位 | 守炉童子 |
| **分裂/召唤** | 逼你 AOE | 裂隙守卫 |
| **精英** | 掉落奖励 | 每层一个 |

**不要设计"纯粹更肉"的敌人**。血量高但没有新行为，只是拉长时间。

## 掉落与节奏

```
普通怪    30% 掉碎片
精英怪    必掉碎片 + 20% 掉新法术
宝箱      50% 碎片 / 30% 法术 / 20% 属性
关底      稀有词条三选一
```

**每层的时长与掉落密度要匹配**：90 秒的层要有约 8-10 次掉落，150 秒的层要有 15 次左右。**不要让玩家长时间没有进化反馈。**

## 视觉与音效的原则

- 每层一个主色调（炼气绿 → 渡劫紫），让人一眼知道自己在哪
- 危险区域必须有明确的预警（变色、闪烁、地面标记），不能突然掉血
- 音效区分：命中 / 受击 / 进化 / 掉落，四种必须不同

## 还没定的

1. **6 层怎么抽**：是否保证每层都抽到关底？现在计划是"第三、六、九层必出"，中间随机抽三层。
2. **跳过层级是否给补偿**：跳过一层会不会让玩家太弱？
3. **单层内是否有波次**：还是持续刷怪到时间结束？现在计划是持续刷，不设波次，减少节奏打断。
