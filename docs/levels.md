## 逐关设计

### 第 1 关 · 乱葬岗（炼气）

| 项 | 内容 |
|---|---|
| 场景 | 荒坟、残碑、歪斜的枯树 |
| 敌人 | 腐尸（不动）、噬骨鸦（俯冲） |
| 机制 | **无。**这是教学关 |
| 时长 | 90 秒 |
| 目的 | 教会三件事：移动、出手、吃道行 |

**为什么第一关必须是纯杂兵**：玩家刚选完流派，需要一段没有压力的时间
去感受"我这套技能怎么用"。第 1 关就上技能怪会劝退。

### 第 2 关 · 断魂涧（筑基）

| 项 | 内容 |
|---|---|
| 场景 | 一道深涧，两侧岩壁，中间只有窄路 |
| 敌人 | 水鬼（游动）、毒蛇（蛇形）、涧蛟仆从（吐水）、涧中老蛟 |
| 机制 | **地形收窄**。可活动宽度只有屏幕的 60% |
| 时长 | 100 秒 |

**设计意图**：上一关可以站远处打，这一关不行了。逼你考虑近身。
如果玩家选的是道人，这一关会让他第一次感到"灵力不够用"。

### 第 3 关 · 枯骨庙（金丹）★

| 项 | 内容 |
|---|---|
| 场景 | 破庙，供着一尊骨佛，香炉还在冒烟 |
| 敌人 | 香火鬼（飘）、骨僧（骨刺阵）、庙中骨佛 |
| 机制 | **香炉**。场上四个香炉，每 2 秒全场掉 3 血，打掉才停 |
| 时长 | 120 秒 |

**设计意图**：第一次"打 Boss 不只是打血条"。香炉是必须处理的机制。
剑客要冲进去砸，道人要远程点，魔头用毒磨——三种解法。

### 第 4 关 · 万剑冢（元婴）

| 项 | 内容 |
|---|---|
| 场景 | 满谷断剑，插在地上 |
| 敌人 | 无主飞剑（直线冲）、剑灵（剑气斩） |
| 机制 | **剑阵扫过**。每 8 秒一排飞剑横扫，1.5 秒预警 |
| 时长 | 120 秒 |

**设计意图**：节奏关。不能站桩，必须持续移动。
剑客在这一关有"主场感"——同样的东西，但你这套技能就是为它准备的。

### 第 5 关 · 镜心湖（化神）

| 项 | 内容 |
|---|---|
| 场景 | 湖面如镜，倒映的不是你 |
| 敌人 | 妄念（复制你的轨迹）、心魔（复制你的法术） |
| 机制 | **画面去饱和**。视野边缘收窄到 70%，看不清角落 |
| 时长 | 120 秒 |

**设计意图**：这一关的难度不靠数值，靠**感知**。
看不清会让玩家紧张，而心魔会用它自己的法术打你。

**没有妖将**：让玩家喘口气。这一关是情绪关，不是硬仗。

### 第 6 关 · 悬空栈道（炼虚）★

| 项 | 内容 |
|---|---|
| 场景 | 贴在绝壁上的木板路，多处已经断了 |
| 敌人 | 山魈（扑击）、坠石（定点落下）、守栈人 |
| 机制 | **断口扩大**。每 10 秒，随机一段栈道消失，地面区域变小 |
| 时长 | 130 秒 |

**设计意图**：位移关。走位空间越来越小，必须提前规划。

**守栈人不主动攻击**，他只推你。这是全篇最重的一场戏。

### 第 7 关 · 双生洞（合体）

| 项 | 内容 |
|---|---|
| 场景 | 一个洞口，两条路，通向同一个大厅 |
| 敌人 | 双子道人（共享生命，独立回复） |
| 机制 | **只有两个精英**，不刷杂兵 |
| 时长 | 140 秒 |

**设计意图**：DPS 检验。单点爆发流在这里会输——你打一个，另一个回血。

**没有杂兵**：这一关是纯 Boss 战，节奏上是个停顿。

### 第 8 关 · 雷池（大乘）

| 项 | 内容 |
|---|---|
| 场景 | 被雷劈了千年的焦土，地面有裂纹 |
| 敌人 | 天兵（成群）、雷兽（引雷）、雷部残将 |
| 机制 | **定点落雷**。随机位置出现预警圈，1 秒后落雷 |
| 时长 | 150 秒 |

**设计意图**：资源管理关。血量、灵力、魔气都在这一关见底。
如果流派没成型，这一关打不过去。

### 第 9 关 · 九霄（渡劫）★

| 项 | 内容 |
|---|---|
| 场景 | 云海之上，什么也没有。一道门，门前坐着一个和你一样的人 |
| 敌人 | **道**（三阶段） |
| 机制 | 每阶段换一套机制 |

**三阶段**：

| 阶段 | 形态 | 用什么打你 |
|---|---|---|
| 一 | 人形 | 你会过的所有法术 |
| 二 | 雷云 | 全场落雷 + 召唤天兵 |
| 三 | 你自己 | 你的流派、你的习惯 |

**设计意图**：最终的敌人是你自己。你的流派越强，它越强。

## 关与关之间的节奏

```
难度
 ↑
 │        ★3           ★6        ★9
 │       ╱ ╲          ╱ ╲       ╱
 │      ╱   ╲        ╱   ╲     ╱
 │  1  ╱  2  ╲  4   ╱ 5   ╲ 7 ╱ 8
 └─────────────────────────────────→ 关
      教学   压力   喘息   重压  终点
```

- 第 1 关教学
- 第 2 关第一次压力
- 第 3 关关底
- 第 4 关节奏
- 第 5 关喘息（情绪关）
- 第 6 关关底（剧情重）
- 第 7 关纯 Boss（停顿）
- 第 8 关最高压
- 第 9 关终点

**第 5 关和第 7 关是刻意的"低谷"**，让玩家在两次高潮之间有恢复。

## 还没定的

1. **每关的敌人组合是否随机**？现在设计是固定的档位，具体刷怪随机。
2. **难度是否随通关次数提升**？现在不提升。加难度会让老玩家有挑战，但也会让新手更难。
3. **第 5 关的"接受心魔"是否影响第 9 关的第三阶段**？现在设计是影响——接受了心魔，第三阶段的"你自己"会更强。
